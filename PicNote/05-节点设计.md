# 竹节笔记 / Bambootes · 05 节点设计

本文规定节点结构、独立编辑页面、插入、移动与合并行为。节点交互以本文为准；存储和 Markdown 规则见 [02-文档与本地存储.md](02-文档与本地存储.md)。实现直接使用最终结构，不兼容旧设计，不编写迁移、回填或旧类型适配逻辑。

## 1. 节点类型与固定位置

| 类型 | `kind` | 内容与限制 |
| --- | --- | --- |
| 标题 | `title` | 每篇文档唯一，固定第 1 位；必填，与 `DocumentEntity.title` 同步；不能创建、删除、移动或合并 |
| 引言 | `introduction` | 第 2 位始终保留主引言，允许为空，不能删除、移动或合并；菜单可在后续位置创建额外引言，额外引言非空、可移动与删除，不添加图片 |
| 章节标题 | `chapter` | 必填标题，可移动与删除，不能合并或添加图片；Markdown 输出 H2 |
| 正文 | `body` | 文字、图片或图文至少有一项；统一类型，不按有无图片拆为 `text / image` |

新建文档与教程均一次性创建标题、主引言。用户未填写引言时仍保留空主引言，阅读和导出不输出空引用。标题只输出一次 H1；标题节点编辑和抽屉重命名在同一事务中同步两个标题字段。

真实节点按当前顺序显示数字标题：`01`、`02`……`99`、`100`。采用 `padStart(2, '0')`，不截断三位以上数字。编号只用于节点页，不写入正文和 Markdown，链尾插入入口不显示编号。编号放在左侧节点圆点正下方，只显示数字，不附带节点类型文字；卡片上方不再显示编号或类型标题。类型文字放在右上角笔形编辑按钮左侧，与按钮一起渐显渐隐。空主引言也有明确的编辑入口。

## 2. 链尾与插入菜单

节点页始终比已保存节点多一个链尾空白插入节点。该项是界面入口，不入库、不计入文档节点数、不导出、不允许编辑、删除、拖动、合并或上移下移；保留圆点且不显示编号，右侧保留“＋ 添加节点”文字入口，宽度随文字，上下各留 8dp 内边距；不使用固定 72dp 高、铺满横向空间的卡片、背景或描边。没有选中文档时不显示此入口，先创建文档。

普通节点圆点菜单将创建入口合并为“插入上一个”。点击后同一菜单位置切换为二级菜单，完全替代一级菜单，提供“引言 / 章节标题 / 正文”及返回一级菜单入口；不保留任何“插入下一个”、前后方向或单独创建章节入口。选择类型后打开独立创建页面，保存成功才入链。

标题和主引言的菜单不允许向它们前面插入。其余节点以当前节点为锚点，固定插在该节点前面；链尾圆点与“＋ 添加节点”均直接弹出“引言 / 章节标题 / 正文”类型菜单，不显示“插入上一个”或返回一级菜单入口，将新节点追加在真实节点末尾。取消创建不产生空节点。相册和待选区导入同样追加在空白项之前。

一级菜单保留允许的上移、下移与删除。普通节点不能越过固定前两位；第一个可移动节点没有上移，最后一个已保存节点没有下移；链尾空白项没有任何移动项。排序仅通过菜单操作，不再通过拖动改序。仓储写入同样校验边界，不能只依赖菜单隐藏。

## 3. 卡片与设置显隐

无图节点使用固定 72dp 内容区与 12dp 圆角；标题、引言、章节标题和正文通过各自主题颜色区分。总标题为 24sp 粗体，章节标题为 20sp 中粗，引言与图片正文为 16sp 常规，无图正文为 18sp 常规。引言正文缩进 24dp，使用 `ThemePalette.introductionContent.foreground` 中性灰色，区别于普通正文；节点类型色仍用于圆点和编辑标签。图片正文卡使用 4:3 裁切预览，底部至少 48dp 的渐变层显示最多两行正文。左侧轴栏为编号提供独立可读区域，竖轴不穿过数字；三位及以上编号完整显示。

图片统一显示第一张缩略图；多图用叠层视觉表达，左上角数字徽标显示总图片数。节点编号与图片数位置、语义分开。完整图片在编辑页按顺序竖排，不再在节点卡内横向翻页。

所有真实节点卡单击均只显现右上角编辑控件组：类型名称统一为“标题、引言、章节标题、正文”，文字在左，带圆角描边框的笔形按钮在右；笔形图标及描边框的视觉尺寸为 24dp，外部点击区域为 32dp，不受通用按钮默认最小尺寸扩张，类型文字不单独充当编辑入口。控件按文字实际宽度预留空间，名称完整显示。控件组共用同一个透明度，0.5 秒渐显、停留 3 秒、0.5 秒渐隐；透明度只在绘制阶段读取，不逐帧重组整张卡片。点击笔形按钮才进入编辑页。重复单击取消旧 Job 并重新计时；页面失活、移除或打开编辑页时取消计时。拖动结束不触发编辑。隐藏时整组文字与按钮不接收点击或无障碍焦点；可通过无障碍自定义“编辑节点”操作直接进入编辑。沿用系统动画缩放，关闭动画时直接切换透明度。控件出现时不与正文预览、图片数量徽标重叠；正文区域保持可读，卡片尺寸和正文宽度不随控件显隐跳动。

## 4. 主题颜色

`ThemePalette` 为四类节点提供前景色与背景色，轴圆点、数字标题、类型文字使用前景色，文字卡与图片卡外框使用背景色。正文内容保持主题可读性，不给图片本身染色。

## 5. 拖动合并

正文节点长按拖动，按拖动位置命中其他正文卡片；不再计算插入位置、不调用排序。目标高亮，松手在有效目标上弹出确认：“合并节点”，说明两个编号、图片数量与文字保留顺序。落在空白、原节点、引言、标题或章节标题时取消，无数据变化；章节标题既不能作为源，也不能作为目标。

确认前不改变数据。取消保留两个节点；确认时重新读取同一文档的两个节点并校验仍存在、均为正文。合并以文档原顺序为准，不受拖动方向影响：较前节点保留 ID 与位置；图片按前节点图片、后节点图片的顺序拼接并重排 `sort_index`，转移图片引用后再删除后节点，不删除仍有引用的文件及源 URI 映射；非空文字按前后顺序用换行连接，原 Markdown 内容保留。

节点合并、图片归属变更与文档更新时间在同一 Room 事务内完成，成功后刷新首页、编号、Markdown 和镜像；失败不留下部分合并。复用现有 busy、Job、Mutex 与事务协调重复操作及异步检查，不额外引入 generation / revision 状态。

## 6. 独立编辑页面

所有节点新建与编辑均为 Navigation 3 普通全屏目的地，沿用新建文档页面的进退动画。删除专用编辑浮层 Scene、背景模糊与面板外部点击关闭逻辑；返回后恢复首页 Tab 与滚动位置。

首页右上角“⋯”提供当前文档的重命名、导出文档与删除文档。重命名和删除复用抽屉文档菜单的弹窗，删除需再次确认；导出完成后打开系统分享面板。修改标题也可从标题节点进入编辑。

页面固定顶栏：返回箭头、“节点编辑”或当前创建类型、保存，以及按需操作菜单。正文滚动，正确处理系统栏和键盘 inset。未保存返回仍弹出放弃确认，保存或图片处理中阻止退出和重复提交，失败保留草稿。

标题只显示必填标题输入；引言显示多行引言输入；章节标题只显示必填章节标题；正文显示完整图片及多行文字。完全移除逐图“图片说明”输入与编辑状态，Markdown 图片替代文本统一按图片顺序生成“图片 N”。不删除节点的正文或备注输入。

正文菜单提供添加图片、按图替换和移除、删除节点；固定标题和主引言不提供删除。图片按真实比例完整展示，沿用公共阴影；编辑列表按图片草稿 ID 懒加载，避免合并后的多图节点一次加载所有图片，正文草稿仍由目的地 ViewModel 保存。移除最后一张图片后，有正文则保留正文节点；内容全空不能保存，可选择删除非固定节点。独立页面保留原草稿、图片准备及失败处理能力。

## 7. 验收场景

- 新建无引言文档的标题、主引言分别在圆点下方显示 `01`、`02`，末尾插入入口不显示编号；类型文字仅随右上角编辑按钮显现，教程同样包含固定前两项。
- 在节点前插入三种允许类型及链尾追加；普通节点的二级菜单替代一级菜单，链尾两个入口直接显示类型菜单，取消不写入；全链不存在“插入下一个”。
- 标题与主引言不移动，其他节点不能越界；末尾入口无移动项，最后一个真实节点不能下移。
- 标题编辑与重命名同步，阅读和导出只出现一个 H1；空引言、链尾项和编号不进入 Markdown。
- 五套主题分别显示四种类型色，引言正文更灰；文字与图片卡的 24dp 编辑控件通过 32dp 点击区进入独立编辑页，类型标签同步显隐且正文不跳动。
- 链尾添加入口为文字加上下各 8dp 内边距，不再显示大型添加卡片。
- 正反方向拖动正文均按原顺序合并图片和文字，先确认；取消、无效落点、章节目标无变更；重启后合并结果保留。
- 图片删除、替换、合并后引用和源 URI 映射正确，未引用文件按既有流程清理，镜像失败仍可重试。
