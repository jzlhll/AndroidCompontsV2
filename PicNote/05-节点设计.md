# 竹节笔记 / Bambootes · 05 节点设计

本文规定节点结构、独立编辑页面、插入、移动与合并行为。节点交互以本文为准；存储、旧版数据兼容和 Markdown 规则见 [02-文档与本地存储.md](02-文档与本地存储.md)。

## 1. 节点类型与固定位置

| 类型 | `kind` | 内容与限制 |
| --- | --- | --- |
| 标题 | `title` | 每篇文档唯一，固定第 1 位；必填，与 `DocumentEntity.title` 同步；不能创建、删除、移动或合并 |
| 引言 | `introduction` | 每篇文档唯一，固定第 2 位，随文档自动创建，允许为空；后续只允许编辑，不能单独新增、删除、移动、合并或添加图片 |
| 章节标题 | `chapter` | 必填标题，可移动与删除，不能合并或添加图片；Markdown 输出 H2 |
| 正文 | `body` | 文字、图片或图文至少有一项；统一类型，不按有无图片拆为 `text / image` |

新建文档与教程均一次性创建标题、主引言。用户未填写引言时仍保留空主引言，阅读和导出不输出空引用。标题只输出一次 H1；编辑 `title` 节点时在同一事务中同步两个标题字段。

真实节点按当前顺序显示数字标题：`01`、`02`……`99`、`100`。采用 `padStart(2, '0')`，不截断三位以上数字。编号只用于节点页，不写入正文和 Markdown，链尾插入入口不显示编号。`NodeMenu` 使用透明竹枝图 `node_bamboo_long_branch.webp`，显示尺寸为宽 27dp、高 48dp；容器宽 48dp、高 68dp，编号从容器顶部 52dp 处开始显示。编号放在左侧竹枝图正下方，只显示数字，不附带节点类型文字；卡片上方不单独显示编号或类型标题，分区说明统一骑缝显示在卡片上边缘中央。右上角仅保留渐显渐隐的带框笔形编辑图标。空主引言也有明确的编辑入口。

节点 Tab 的 `title / introduction / chapter` 使用骑缝分区标签，分别显示“标题 / 引言 / 章节NN”。卡片保持 12dp 圆角，不添加常态描边；标签为 13sp 中性灰字，水平居中，文字高度中线与卡片上边缘重合，左右各留 12dp，背景为 6dp 圆角。标签背景直接复用当前主题 `ThemePalette.nodeColors(kind).background` 的柔和节点底色，文字使用 `ThemePalette.introductionContent.foreground`；随主题与节点类型切换，不使用纯白或独立硬编码色值。`NodeCardSection` 按标签实际高度测量，在卡片外额外预留半个标签高度，避免字体放大时裁切；卡片内容区仍为 72dp，正文 padding 继续以卡片外框为基准。普通 `body` 不添加分区标签；合并候选沿用原有高亮描边。

章节编号按当前节点顺序仅统计 `chapter`，从“章节01”递增，至少两位、不截断三位以上数字；插入、移动或删除章节后自动重新编号。文档 Tab 通过 `ChapterDivider` 保留独立的灰色分隔行：13sp 文字，左右各空出 12dp 后连接等宽横线。两种展示共用章节编号规则，不写入数据库或 Markdown，导出仍使用标准章节标题。

## 2. 链尾与插入菜单

节点页始终比已保存节点多一个链尾空白插入节点。该项是界面入口，不入库、不计入文档节点数、不导出、不允许编辑、删除、拖动、合并或上移下移；不显示圆点、编号或竖轴延长线，仅保留与卡片左侧对齐的“＋ 添加节点”文字入口，宽度随文字，上下各留 8dp 内边距；不使用固定 72dp 高、铺满横向空间的卡片、背景或描边。没有选中文档时不显示此入口，先创建文档。

普通节点圆点菜单的创建入口为“插入节点”。点击后同一菜单位置切换为二级菜单，完全替代一级菜单，仅提供“章节标题 / 正文”及返回一级菜单入口；不保留任何“插入下一个”、前后方向或单独创建章节入口。选择类型后打开独立创建页面，保存成功才入链。

标题和主引言的菜单不允许向它们前面插入。其余节点以当前节点为锚点，固定插在该节点前面；链尾“＋ 添加节点”直接弹出“章节标题 / 正文”类型菜单，不显示“插入节点”或返回一级菜单入口，将新节点追加在真实节点末尾。取消创建不产生空节点。相册和待选区导入同样追加在空白项之前。

一级菜单保留允许的上移、下移与删除。普通节点不能越过固定前两位；第一个可移动节点没有上移，最后一个已保存节点没有下移；链尾空白项没有任何移动项。排序仅通过菜单操作，不再通过拖动改序。仓储写入同样校验边界，不能只依赖菜单隐藏。

## 3. 卡片与设置显隐

无图节点使用固定 72dp 内容区与 12dp 圆角；标题、引言、章节标题和正文通过各自主题颜色区分。总标题为 24sp 粗体，在节点页卡片与文档页中均居中显示；节点页在左右等量文字 padding 后的区域中居中，编辑控件位于右上角，控件显隐不改变标题位置。章节标题为 20sp 中粗，引言与图片正文为 16sp 常规，无图正文为 18sp 常规。引言使用 `ThemePalette.introductionContent.foreground` 中性灰色，区别于普通正文；节点类型色仍用于圆点和编辑图标。图片正文卡使用 4:3 裁切预览，底部至少 48dp 的渐变层显示最多两行正文。左侧轴栏为编号提供独立可读区域，竖轴不穿过数字；三位及以上编号完整显示。

### 节点文字 padding

`NodeCard` 的文字 padding 统一按下表设计，单位为 dp，左右以最前层卡片的完整外框为基准计算文字区域的内边距。左、右在代码中分别使用 `start`、`end`；文字布局上下不额外添加固定 padding，由对应容器的高度与垂直居中决定实际留白。

| `kind` | 文字区域 | 左 padding | 右 padding | 额外上 / 下 padding | 高度与对齐 |
| --- | --- | --- | --- | --- | --- |
| `title` | 标题 | 16 | 16 | 0 / 0 | 固定 72dp，水平与垂直居中 |
| `introduction` | 引言预览与空内容提示 | 32 | 24 | 0 / 0 | 固定 72dp，垂直居中 |
| `chapter` | 章节标题 | 16 | 24 | 0 / 0 | 固定 72dp，垂直居中 |
| `body` | 无图正文预览与空内容提示 | 16 | 24 | 0 / 0 | 固定 72dp，垂直居中 |
| `body` | 单图、多图卡片底部备注 | 16 | 24 | 0 / 0 | 渐变文字层最小 48dp，垂直居中 |

文字区域按完整卡片宽度减去表内左右 padding 测量。`NodeEditControls` 作为右上角覆盖层独立绘制，不参与文字区域的测量或占位，显隐不改变文字宽度、位置或换行。图片备注的左右数值已包含 4dp 图片外框，因此图片内容区内的 padding 分别为 12dp / 20dp；多图卡片同样以最前层卡片外框为基准，后方堆叠装饰不计入文字区域。

后续新增节点类型或文字展示分支时，必须同步补充本表，明确左右 padding、上下留白规则及高度、对齐方式；除 `title` 与 `introduction` 的专用设计外，默认左右为 16dp / 24dp，需要差异时在本表中明确设计后再实现。

图片初始显示第一张；多图用叠层视觉表达，整个堆叠卡片下方单独显示一行圆点指示当前图片，上间距 8dp、圆点 6dp、下间距 6dp，节点总高度相应增加 20dp；圆点使用主题前景色区分选中状态。堆叠卡片支持左右滑动循环查看，最后一张继续向左滑动回到第一张，第一张向右滑动进入最后一张；无障碍的上一张、下一张操作采用相同循环规则，浏览位置在配置变化时保留，不修改数据库、文档顺序或 Markdown。完整图片在编辑页按顺序竖排。

点击多图卡片后，同时显现底部左右箭头；当前为第一张时不显示左箭头，最后一张时不显示右箭头。箭头图标为 18dp，圆形背景为 24dp，点击区域为 42dp。箭头用于调整顺序：左箭头将当前图片与前一张交换，右箭头将当前图片与后一张交换。先播放从箭头位置扩散的水波纹，再提交顺序；保存成功后保持当前查看位置，待新图片加载完成后用 240ms 淡入。例如 A、B、C 当前查看 A，点右箭头后保存为 B、A、C 并显示 B，再点右箭头换回 A。相邻交换即时落盘并同步文档页及 Markdown 镜像；失败保留原图与顺序。箭头与编辑控件共用显隐计时；没有备注时箭头位于卡片底部，有备注时箭头排在备注上方并留 2dp 间距，备注因此可以贴左排布，不再为箭头在两侧预留空间。圆点位于卡片外，不占用图片与备注区域。

普通模式下，所有真实节点卡单击均显现右上角带圆角描边框的笔形编辑图标；笔形图标及描边框的视觉尺寸为 24dp，按钮区域为 32dp，不受通用按钮默认最小尺寸扩张。右上角仅显示编辑图标，作为覆盖层绘制，正文不为其缩窄或额外留白；显现期间允许遮挡其下方的预览文字。编辑图标沿用透明度动画，0.5 秒渐显、停留 3 秒、0.5 秒渐隐；透明度只在绘制阶段读取，不逐帧重组整张卡片。点击编辑图标进入编辑页。重复单击取消旧 Job 并重新计时；页面失活、移除或打开编辑页时取消计时。拖动结束不触发编辑。隐藏时编辑图标不接收点击或无障碍焦点；可通过无障碍自定义“编辑节点”操作直接进入编辑。沿用系统动画缩放，关闭动画时直接切换透明度。卡片尺寸和正文宽度不随控件显隐跳动。

`NodeEditControls` 与多图箭头仅在可交互且透明度大于 0 时参与组合和测量，淡出至 0 后移除；隐藏的箭头行仅用 42dp 高的空白占位，保持字体放大时备注可用空间一致，卡片尺寸与底部备注位置保持不变。无分区标签的卡片直接布局内容，不创建 `NodeCardSection` 的自定义测量层。菜单关闭与拖动清理等同步状态更新使用有条件的 `SideEffect`；图片首次显示直接加载，仅在图片文件切换时创建加载状态、淡入动画与协程，保留旧图直至新图完成 240ms 淡入，主图加载组件在淡入前后保持同一组合位置。换图取消沿用 `LaunchedEffect` 的键与结构化取消机制。

## 5. 节点合并

节点 Tab 右上角提供“合并”入口，至少存在两个正文节点时可用；横屏入口位于右侧列表上方靠右处。进入选择模式后，正文卡片右上角显示勾选框，单击卡片任意区域切换选中状态，选中卡片通过主题 primary 描边强调。标题、引言、章节标题与链尾插入项不可选；暂停原单击显现编辑图标、图片切换与前移后移按钮、拖动及节点菜单，隐藏底部图片导入入口。右上角改为“取消”和“合并（N）”，选中至少两个正文节点后才能请求合并。取消确认框保留选择，确认提交后退出选择模式。“取消”、返回键、切换 Tab、打开文档抽屉或离开首页退出选择模式，屏幕旋转保留当前选择。

普通模式下，正文节点仍支持长按拖动，按拖动位置命中其他正文卡片；不计算插入位置、不调用排序。目标高亮，松手在有效目标上请求合并。落在空白、原节点、引言、标题或章节标题时取消，无数据变化；章节标题既不能作为源，也不能作为目标。拖动与多选共用“合并节点”确认框，说明所选编号、图片总数、文字保留顺序与保留位置。

拖动卡片沿拖动方向超出列表可见区域的上、下边界时，列表持续小步向对应方向滚动；卡片回到可见区域、列表到达边界、松手、取消或页面失活后停止。拖动期间临时保留源卡片，补偿列表滚动带来的位移，使卡片继续跟随手指，并按滚动后的卡片位置更新合并候选；显示区域外松手取消合并。

确认前不改变数据。取消保留所有节点；确认时重新读取同一文档的全部所选节点并校验至少两个、ID 不重复、仍存在且均为正文。合并以文档原顺序为准，不受勾选顺序或拖动方向影响：最前节点保留 ID 与位置；图片按各节点原顺序拼接并重排 `sort_index`，转移全部图片引用后再删除其余所选节点，不删除仍有引用的文件及源 URI 映射；非空文字按原顺序用换行连接，原 Markdown 内容保留。未选节点及其顺序保持不变。

节点合并、图片归属变更与文档更新时间在同一 Room 事务内完成，成功后刷新首页、编号、Markdown 和镜像；失败不留下部分合并。复用现有 busy、Job、Mutex 与事务协调重复操作及异步检查，不额外引入 generation / revision 状态。

## 6. 独立编辑页面

所有节点新建与编辑均为 Navigation 3 普通全屏目的地，沿用新建文档页面的进退动画。删除专用编辑浮层 Scene、背景模糊与面板外部点击关闭逻辑；返回后恢复首页 Tab 与滚动位置。

首页右上角“⋯”提供当前文档的导出文档与删除文档。删除复用抽屉文档菜单的确认弹窗；导出完成后打开系统分享面板。修改标题统一从 `title` 节点进入编辑。

页面固定顶栏：返回箭头、“节点编辑”或当前创建类型、保存，以及按需操作菜单。正文滚动，正确处理系统栏和键盘 inset。未保存返回仍弹出放弃确认，保存或图片处理中阻止退出和重复提交，失败保留草稿。

标题只显示必填标题输入；引言显示多行引言输入；章节标题只显示必填章节标题；正文显示完整图片及多行文字。完全移除逐图“图片说明”输入与编辑状态，Markdown 图片替代文本统一按图片顺序生成“图片 N”。不删除节点的正文或备注输入。

`EditorScreen` 竖屏时，“添加图片”入口在页面内容区居中，正文或备注输入框靠左并保留 24dp 边距；横屏有图时，两者的内容区域起点与图片左边缘一致，“添加图片”入口在该区域内居中。

正文创建、编辑页在图片列表下方提供“添加图片”入口打开系统选图；已保存且允许删除的节点在顶栏显示主题错误红色的“删除”文字按钮，点击后弹出二次确认，确认后才删除；确认弹窗标题及“确认”按钮同样使用错误红色。固定标题和主引言不提供删除。每张图片左侧显示编号，下方依次竖排上移、下移、替换、移除四个图标按钮；上移、下移交换相邻图片的草稿顺序，首张禁用上移，末张禁用下移；替换直接打开单选图片选择器，移除只切换草稿的待删除状态，保留原图位置并覆盖 50% 透明白色遮罩，再次点击取消移除，替换图片后清除该图的待删除状态。移除图标使用普通文本颜色 `MaterialTheme.colorScheme.onSurface`，随主题切换。图片按真实比例完整展示，沿用公共阴影；编辑列表按图片草稿 ID 懒加载，顺序调整保留图片 ID 和草稿内容，正文草稿及待删除状态由目的地 ViewModel 保存。点击保存后才排除待删除图片，图片顺序与正文一并提交并同步文档页及 Markdown 镜像；返回放弃则不改变已保存图片与顺序，保存失败保留待删除状态。全部图片标记待删除后，有正文则保留正文节点；内容全空不能保存，可选择删除非固定节点。独立页面保留原草稿、图片准备及失败处理能力。

## 7. 验收场景

- 新建无引言文档的标题、主引言分别在圆点下方显示 `01`、`02`，末尾插入入口不显示编号；右上角仅显现编辑图标，教程同样包含固定前两项。
- 在节点前插入 `chapter / body` 及链尾追加；普通节点的二级菜单替代一级菜单，链尾入口直接显示类型菜单，取消不写入；所有创建菜单均不提供 `introduction`，仓储同样拒绝新增 `introduction`；全链不存在“插入下一个”。
- 标题与主引言不移动，其他节点不能越界；末尾入口无移动项，最后一个真实节点不能下移。
- 节点 Tab 的 `title / introduction / chapter` 标签骑缝居中显示在卡片上边缘，常态无描边，标签背景与卡片底色共同随主题切换；字体放大时完整显示，卡片内容区高度和正文 padding 保持规范；文档 Tab 继续使用独立章节分隔行。
- 编辑 `title` 节点同步文档标题，阅读和导出只出现一个 H1；空引言、链尾项和编号不进入 Markdown。
- 五套主题分别显示四种类型色，引言正文更灰；文字与图片卡的 24dp 编辑控件通过 32dp 点击区进入独立编辑页，编辑图标显隐时正文不跳动。
- 链尾添加入口为文字加上下各 8dp 内边距，不再显示大型添加卡片。
- 正反方向拖动或多选两个及以上正文均按原顺序合并图片和文字，先确认；选择模式单击只切换勾选，滚动后选择保留；取消、无效落点、章节目标无变更；重启后合并结果保留。
- 图片删除、替换、合并后引用和源 URI 映射正确，未引用文件按既有流程清理，镜像失败仍可重试。

## 8. 启动操作引导

每个进程只在第一个前台 `onStart` 事件（`foregroundOrdinal == 1`）检查一次，复用现有前台事件入口。菜单与卡片两类引导互斥，按菜单优先、卡片其次选择一项；确认后本次启动不再接着展示另一项。

`NodeGuidePreferences` 分别保存两类全局点击总数、引导阶段和首次确认时的点击总数，全部为 `Long`。左侧圆点／编号打开操作菜单只累计菜单次数；点击卡片显现控件只累计卡片次数，滑动、箭头、编辑按钮及“知道了”不混入统计。两类点击均通过 module 的 `Modifier.onClick` 防抖，复用 View `onClick` 的 `acceptClick` 规则，通过防抖后才记数；引导完成后继续累计。

阶段 `0` 表示尚未确认，`1` 表示已确认一次，`2` 表示完成。点击“知道了”持久化下一阶段，最多确认两次；点击总数超过两次，或首次确认后出现新点击，也进入完成阶段。阶段与点击计数在同一 DataStore 事务内更新。

检查在 `withIOThread` 中优先读取完成阶段；两类都完成时直接返回，不等待文档或查找目标。仍有未完成项时等待首页初始加载，再在后台判断当前文档至少有四个真实节点、不是 `WelcomeDocumentId`、对应点击次数至多两次；阶段为 `1` 时还要求点击总数没有增加。只有命中后才回主线程设置 `HomeState.nodeGuide`；前后台切换、配置变化和重组不重复检查。

引导使用全屏 Dialog，关闭系统额外 dim，仅绘制 40% 黑色遮罩。菜单引导显示节点 Tab 并定位到真实 `03` 编号，气泡从右侧指向编号，提示单击左侧的节点可弹出操作菜单。卡片引导保留列表滚动位置，按卡片与列表视口的交集选取目标：优先选择可见的图片卡片，其中有图的 `03` 优先，其次其他有图的普通节点；没有可见图片卡片时，再按 `03`、其他普通节点、`01`／`02` 的顺序选择文字卡片。气泡放在目标上方或下方，告知点击可显示更多操作；保留系统栏安全距离并提供“知道了”，确认保存成功后隐藏，失败可重试。
