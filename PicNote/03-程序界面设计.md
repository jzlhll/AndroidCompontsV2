# 竹节笔记 / Bambootes · 03 程序界面设计

## 1. 全局结构

单 `ComponentActivity` + Navigation 3，顶部为左侧 navMenu、文档标题与右侧“⋯”，标题栏内容区固定 84dp 高；标题栏下留 12dp，再显示固定的 `节点 / 文档` 两个 Tab，由 Compose Foundation `HorizontalPager` 承载，各页独立保存滚动位置。当前文档的两个页面保持组合，切换 Tab 复用节点摘要、Markdown 解析结果和已创建的阅读视图。选中 Tab 的底部指示线固定为 51dp，居中显示在对应 Tab 下方。

根组件统一承载 Navigation 3 导航。首次进入显示已初始化的教程文档；“＋新建”与所有节点创建、编辑均使用独立全屏页面和 220ms 横向进退动画，返回后恢复首页 Tab 与滚动位置。

页面以图片和用户文字为中心，保留留白和细分隔线。没有会话页、模型入口、解析状态或结果摘要；扫描、导入、保存和导出期间提供简短忙碌反馈并阻止重复提交。

顶栏“⋯”提供当前文档的重命名、导出文档与删除文档。重命名与删除复用抽屉文档菜单的弹窗，删除仍需确认；菜单中的“删除文档”、删除确认标题及确认按钮统一使用主题错误红色。导出完成后打开系统分享面板。标题也可从标题节点编辑。教程使用本地化标题，其他新建文档使用创建时填写的非空标题。

首页加载、文档操作与前台图片检查进行时，仅在两个 Tab 正中间覆盖显示 24dp 的圆形 loading，结束后隐藏；Tab 高度、文档内容区域与滚动状态不随进度变化，不插入额外进度条或扫描结果行。图片检查仅在应用回到前台时执行一次，右上角不提供刷新按钮。首次建立基线、恢复权限后重建基线或没有变化时，不显示成功提示和零值计数；有待选新图时通过左下提示入口展示。错误或权限提示放在 Tab 下方。未完整授权时显示“图片权限：未授权 / 部分图片”与一个小箭头，保留至少 48dp 的点击热区和授权入口的无障碍说明；点击后主动进入授权流程，无法继续请求或仅部分授权时可进入系统设置，不并列摆放多个文字按钮。

首次用途弹窗标题为“授予图片访问权限”，简短说明完整授权用于进入时比较图片变化，手动选图无需此权限；按钮为“授予权限”和“暂不授权”。已提示状态保存到 DataStore，后续不再主动弹窗；相册添加、编辑中添加与替换图片始终可通过 Photo Picker 使用。

字段使用简短标签，不重复添加占位说明、插入位置解释或技术名词；保留必要错误、权限用途与删除后果提示。

## 2. 文档抽屉与新建

抽屉约占屏幕宽度的 86%，标题栏内容区固定 84dp 高。左上始终为“我的文档”，右上为“＋ 新建”；当前项使用主题选中色高亮，并向无障碍服务提供选中状态。每项仅展示标题、节点数与简短时间，行内菜单提供重命名和删除，删除入口固定使用红字。

首次进入自动显示教程，不提供“空空如也”页面。用户主动删除全部文档后，列表与正文留空，仍可从抽屉新建。抽屉底部保留“外观”入口，可选择 Black、White、Dracula、Sage、Alucard，单选按钮与主题名称间距为 8dp，不另建设置页。

点击“＋ 新建”打开独立的“新建文档”页面，显示必填的“标题”和“引言（可选）”两个输入框。左侧使用返回箭头，右侧按钮为“创建”。标题去除首尾空白后不能为空，标题为空时禁止提交；点击“创建”且保存成功后才生成文档。返回或取消不创建文档。

新建文档固定创建第一个 `title` 节点与第二个 `introduction` 节点；引言允许为空。链尾始终展示一个不入库的空白插入节点，可创建引言、章节标题或正文节点。没有目标文档时，从相册或待选图片入口也先完成创建页面，再继续选图或导入。

内置教程依次展示标题、120 字符引言、手机桌面图、“点击程序打开程序。”和 `TODO` 章节。引言使用 72dp 圆角卡，文字固定缩进 24dp，颜色使用 `ThemePalette.introductionContent.foreground`；文档阅读保持 24dp 总缩进与灰字，并为完整引言块添加 8dp 圆角灰色背景。中英文资源和首次初始化规则见 [04-首次使用文档.md](04-首次使用文档.md)。

## 3. 节点页

节点结构与交互统一见 [05-节点设计.md](05-节点设计.md)：标题、引言、章节标题、正文四类节点，固定前两项、链尾插入项、两位起步编号、主题类型色、二级插入菜单与拖动确认合并。编号单独显示在左侧圆点下方，类型文字放在右上角带框笔形按钮左侧，与按钮共同渐显渐隐；所有真实节点通过该按钮进入独立编辑页面。

### 底部操作

内置教程通过固定 `WelcomeDocumentId` 识别，隐藏底部相册浮动按钮、左下新图提示与图片待选纸带，不依赖教程标题或语言。普通文档不保留常驻底部操作条，右下使用浮动“＋”按钮打开相册。有待选新图时，在左下同一水平位置显示小框：最新一张图片为 48dp 方形缩略图，旁边显示“新增N”；没有候选时不显示此框。两个入口距离侧边各 16dp，并保留系统底部安全间距；列表底部预留滚动空间，避免末项被浮动按钮遮挡。

纸带默认收起，点击左下新图框展开或收起；展开后沿用缩略图勾选、“忽略”和“添加 N 张”，相册按钮与新图框位于纸带上方。确认后转换为质量 90 的 WebP 并追加到链尾。同一文档已导入的图片默认不重复选择；导入时以源内容 hash 再次去重。候选跨进入保留，关闭纸带不消费；“忽略”只处理勾选项。候选全部消费后收起纸带并隐藏新图框。右下浮动按钮使用系统 Photo Picker，多选顺序以返回顺序为准；取消不修改文档。选图后后台准备本地图片，编辑器添加或替换也使用同一流程；处理期间阻止重复操作，失败保留当前内容。

## 4. 节点编辑页面

节点创建与编辑均使用独立全屏页面，顶栏固定返回、标题和保存，正文可滚动并处理键盘 inset。标题与章节标题编辑必填标题，引言编辑多行文字，正文可包含完整比例图片和多行文字；不提供“图片说明”输入项。

返回时确认未保存修改，处理中阻止退出和重复提交，失败保留草稿。具体字段、图片操作和删除边界见 [05-节点设计.md](05-节点设计.md)。

## 5. 文档页

文档页通过 `LazyColumn` 承载 App 内的阅读视图：标题节点为唯一 H1，章节标题节点为 H2，引言、普通文字、图片和备注按链序显示。引言导出为标准 `>` 引用；App 内顶层引用使用 24dp 总缩进、主题中性灰字与 8dp 圆角灰底，内部上下各留 8dp，内边距不重复叠加缩进；普通正文中的引用不改变节点类型。图片按真实宽高比展开，并裁切为 8dp 圆角。

节点页与文档页的内容字号统一使用：总标题 `24sp` 粗体、引言 `16sp` 灰色、章节标题 `20sp` 中粗、无图正文 `18sp` 常规、图片正文 `16sp` 常规。文档页仅总标题下方显示横线，章节标题不显示横线。节点类型标签使用“标题、引言、章节标题、正文”，按实际文字宽度预留编辑控件空间，完整显示类型名称。

App 内文档左右留白各 24dp、顶部留白 12dp。不同节点之间间隔 12dp；同一节点内的图片、图片附带文字及相邻段落间隔 6dp。标题和章节标题额外增加自身上、下各 6dp 留白，因此标题与普通节点之间为 18dp，相邻标题之间为 24dp。独立文字即使位于图片之后，也保留节点间的 12dp。排版保留节点归属并统一解析跨节点引用；字号、圆角和间距仅用于 App 内显示，导出仍为标准 Markdown，不写入阅读标记或视觉样式。

滚动到顶部或底部时，标题、引言和末尾章节必须在当前帧按完整内容测量并显示；文本块不维护独立的滚动偏移，不靠再次滑动、延迟刷新或强制滚回顶部恢复显示。

页面只负责将图片和内容排成可阅读的文档，不提供“编辑文字”、逐块编辑或源码编辑模式。所有修改回到节点的独立编辑页面完成，保存后立即反映到文档页。导出使用同一份已保存内容。

## 6. 尺寸与视觉

基础颜色方案与按钮尺寸和 agit 共用公共 UI 实现。PicNote 使用独立的 `PicNoteTheme`、`ThemePalette` 与 `LocalThemePalette`，按 `BlackPalette / WhitePalette / DraculaPalette / SagePalette / AlucardPalette` 组织基础配色及应用专用的操作颜色；默认 Sage，选择跨启动保存。Alucard 参考 Notepadmm 的 `colors_alucard.css`，使用浅米色底、莓红主色与紫色辅助色。`PicNoteTheme` 统一提供颜色与系统栏明暗，页面、抽屉、编辑页面和 Markdown 阅读随方案更新，图片内容保持不变。

创建文档操作使用 `ThemePalette.createDocument` 的前景色与背景色，通过 `CreateDocumentButton` 应用到抽屉“＋新建”。普通按钮继续使用 Material 3 颜色角色；四类节点的前景色与背景色由 `ThemePalette` 提供，完整色值见 [05-节点设计.md](05-节点设计.md)。按钮沿用 agit 的高度与内容留白，普通图标按钮沿用公共尺寸；节点卡编辑控件按独立约定使用 24dp 视觉与 32dp 点击区域，末尾添加仅使用文字和上下各 8dp 内边距。

| 项目 | 值 |
| --- | --- |
| 背景、面板、文字、操作色与细线 | 使用当前颜色方案对应的 Material 3 颜色角色 |
| 节点图片比例 / 圆角 | `4:3 / 12dp` |
| 文档页引言 / 图片圆角 | `8dp` |
| 文档节点间隔 / 同节点内容间隔 | `12dp / 6dp` |
| 文档标题额外留白 | 上下各 `6dp` |
| 纯文字节点 / 章节节点高度 | 固定 `72dp`，圆角 `12dp` |
| 图片备注层 | 至少 `48dp`，`16sp` 常规文字，最多两行 |
| 节点编辑 | 独立全屏页面 |
| 节点编辑按钮视觉 / 点击区域 | `24dp / 32dp` |
| 末尾添加入口 | 文字大小，上下各 `8dp` 内边距 |
| Tab 选中指示线宽度 | `51dp` |
| 阴影建议值 | 垂直偏移 `10dp`，模糊约 `24dp`，透明度约 `18%` |
| 设置显隐时序 | `0.5s + 3s + 0.5s` |

阴影仅用于抬起完整图片，不作为图片内容滤镜；正文与普通卡片保持平静，避免增加装饰性状态面板。
