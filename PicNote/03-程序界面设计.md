# 图笺 / PicNote · 03 程序界面设计

## 1. 全局结构

单 `ComponentActivity` + Navigation 3，顶部为左侧 navMenu、文档标题与右侧“⋯”；下方固定 `节点 / 文档` 两个 Tab，由 Compose Foundation `HorizontalPager` 承载，各页独立保存滚动位置。

根组件统一承载导航与浮层。首次进入显示已初始化的教程文档；“＋新建”使用独立普通页面与 220ms 横向进退动画，节点编辑在当前首页上方展示，不将首页替换为全屏编辑页。

页面以图片和用户文字为中心，保留留白和细分隔线。没有会话页、模型入口、解析状态或结果摘要；扫描、导入、保存和导出期间提供简短忙碌反馈并阻止重复提交。

顶栏“⋯”提供重命名、复制 Markdown、导出文档。教程使用本地化标题，其他新建文档使用创建时填写的非空标题。

首页仅在扫描中、有实际差异、出错或权限不足时显示紧凑提示；右上角不提供刷新按钮，图片检查仅在应用回到前台时执行一次。首次建立基线、恢复权限后重建基线或没有变化时，不显示成功提示和零值计数。未完整授权时显示“图片权限：未授权 / 部分图片”与一个小箭头，保留至少 48dp 的点击热区和授权入口的无障碍说明；点击后主动进入授权流程，无法继续请求或仅部分授权时可进入系统设置，不并列摆放多个文字按钮。

首次用途弹窗标题为“授予图片访问权限”，简短说明完整授权用于进入时比较图片变化，手动选图无需此权限；按钮为“授予权限”和“暂不授权”。已提示状态保存到 DataStore，后续不再主动弹窗；相册添加、编辑中添加与替换图片始终可通过 Photo Picker 使用。

字段使用简短标签，不重复添加占位说明、插入位置解释或技术名词；保留必要错误、权限用途与删除后果提示。

## 2. 文档抽屉与新建

抽屉约占屏幕宽度的 86%。左上始终为“我的文档”，右上为“＋ 新建”；当前项使用主题选中色高亮，每项仅展示标题、节点数与简短时间，行内菜单提供重命名和删除。

首次进入自动显示教程，不提供“空空如也”页面。用户主动删除全部文档后，列表与正文留空，仍可从抽屉新建。抽屉底部保留“外观”入口，可选择 Black、White、Dracula、Sage，不另建设置页。

点击“＋ 新建”打开独立的“新建文档”页面，显示必填的“标题”和“引言（可选）”两个输入框。左侧使用返回箭头，右侧按钮为“创建”。标题去除首尾空白后不能为空，标题为空时禁止提交；点击“创建”且保存成功后才生成文档。返回或取消不创建文档。

引言非空时作为第一个 `introduction` 节点保存，留空则创建空节点链。空链提供“添加第一个节点”，可选择图片、纯文字或章节。没有目标文档时，从相册或待选图片入口也先完成创建页面，再继续选图或导入。

内置教程依次展示 120 字符引言、手机桌面图、“点击程序打开程序。”和 `TODO` 章节。引言使用 72dp 圆角卡，文字固定缩进 24dp，颜色使用主题的 `onSurfaceVariant`；文档阅读保持同样的缩进与灰字。中英文资源和首次初始化规则见 [04-首次使用文档.md](04-首次使用文档.md)。

## 3. 节点页

### 3.1 节点轴与插入

左侧使用细竖轴，圆点与对应卡片的竖向中点对齐，统一使用中性色。

点击圆点弹出就近菜单：

| 菜单项 | 保存位置与内容 |
| --- | --- |
| 插入上一个节点 | 在所点节点正前方插入，可写纯文或添加图片 |
| 插入下一个节点 | 在所点节点正后方插入，可写纯文或添加图片 |
| 创建章节 · 插在前面 | 输入必填章节标题，固定插在所点节点正前方 |
| 创建章节 · 插在后面 | 输入必填章节标题，固定插在所点节点正后方 |

点击外部关闭菜单。位置以打开菜单时所点节点为准，保存才正式入链，取消不留下空节点。创建章节只填写章节标题，保存后在链上显示为独立章节卡，在文档中显示为 Markdown 二级标题。

长按拖拽排序，松手后保存位置并立即刷新 Markdown；圆点菜单同时提供上移/下移，便于无障碍与跨屏移动。

### 3.2 图片卡

图片宽高比固定为 **4:3**，高度为卡片宽度 × 3/4，使用 `centerCrop`（Compose `ContentScale.Crop`）铺满；小图允许放大变模糊。裁切只用于节点页预览，不改变完整图片。

图片节点默认展示首张图；多张图在同一固定图片框内横向查看。

图片底部用 **32dp** 半透明渐变层展示用户备注，最多两行，超出省略；没有备注时不显示这一层。Markdown 在此转为紧凑的纯文字预览，标题和列表标记不直接展示。

图片区高度由 4:3 比例决定，卡间距仅用于分隔相邻节点。

无图纯文字节点使用固定 **72dp** 高、**12dp** 圆角的浅色卡，宽度与图片卡对齐，左右内边距 14dp；最多显示两行文字，超出省略。无论文字长短都保持 72dp，点击后编辑完整内容。

章节节点也使用 72dp 圆角卡，以较醒目的标题与颜色区别于普通纯文，不重复标注“章节”；点击编辑章节标题。纯文与章节的轴上圆点均与卡片中心对齐。

### 3.3 设置显隐

图片右上角设置默认隐藏。单击图片后 **0.5 秒渐显 → 停留 3 秒 → 0.5 秒渐隐**；再次单击时取消旧隐藏 Job，并从当前透明度重新显现和计时。

点击设置打开图片遮罩，不再触发图片单击。离开页面或打开遮罩时取消计时；关闭系统动画时直接切换透明度。圆点与小图标使用至少 48dp 的交互热区，无障碍提供“打开图片”和“编辑文字”操作。

### 3.4 底部操作

底部只有素材入口：左侧“新图片 N”展开图片待选纸带，右侧“＋ 添加图片”打开相册。没有候选时左侧显示“相册”。

纸带默认收起，展开后提供缩略图勾选、“忽略”和“添加 N 张”；确认后转换为质量 90 的 WebP 并追加到链尾。同一文档已导入的图片默认不重复选择；导入时以源内容 hash 再次去重。候选跨进入保留，关闭纸带不消费；“忽略”只处理勾选项。右侧相册使用系统 Photo Picker，多选顺序以返回顺序为准；取消不修改文档。选图后后台准备本地图片，编辑器添加或替换也使用同一流程；处理期间阻止重复操作，失败保留当前内容。

## 4. 节点编辑遮罩

节点编辑使用同窗口悬浮面板，**整个面板距可用区域左右各 24dp**，保留上下安全距离与圆角。下面的首页保持原位置，取样模糊并叠加轻遮罩；面板中的图片、文字和按钮保持清晰。复用公共背景模糊组件，不支持模糊的平台使用其半透明覆盖降级。

面板内依次展示 **带柔和阴影的完整图片、用户备注输入框**，使用常规内容内边距。固定顶栏，正文限制在可用高度内竖向滚动，键盘出现后仍可访问输入框与保存操作。

- 完整图片按可用宽度和真实比例完整展示，不使用 4:3 裁切。
- 备注输入框放在图片下方，标签为“备注”，允许多行编辑，不重复显示占位说明。
- 多张图按顺序竖排，备注输入框位于全部图片之后；长图继续向下滚动即可编辑备注。
- 纯文字节点不显示图片区，直接展示“文字内容”输入框，非空才可保存；引言展示“引言”输入框，保持独立类型，不提供添加图片入口。
- 顶部固定返回箭头、标题“节点编辑”、“保存”和按需“⋯”菜单，返回入口不使用文字。
- “⋯”提供添加图片、替换图片、移除此图、删除节点，操作按需展开。

点击“保存”一并提交图片与备注修改，返回链上原位置；节点卡底部 32dp 渐变层更新备注，文档页同步显示保存的图片和文字。保存失败保留输入并允许重试，无实际变化时直接关闭。

关闭、点击面板外部或系统返回时，未保存的修改可选择放弃或继续编辑，保存期间不退出。浮层拦截底层首页的点击、滚动与无障碍操作。移除最后一张图片时，非空文字可保留为纯文字节点；空节点则进入删除确认。纯文字、图文和章节共用此浮层。

## 5. 文档页

文档页是简单的 Markdown 阅读预览：文档标题为 H1，章节节点为 H2，引言、普通文字、图片和备注按链序显示。引言导出为 `>` 引用；阅读页的顶层引用统一使用 24dp 缩进与灰字，普通正文中的引用不改变节点类型。图片按真实宽高比展开，文字按用户填写的内容显示。

页面只负责将图片和内容排成可阅读的文档，不提供“编辑文字”、逐块编辑或源码编辑模式。所有修改回到节点页的编辑遮罩完成，保存后立即反映到文档页。复制 Markdown 与导出均使用同一份已保存内容。

## 6. 尺寸与视觉

基础颜色方案与按钮尺寸和 agit 共用公共 UI 实现。PicNote 使用独立的 `PicNoteTheme`、`ThemePalette` 与 `LocalThemePalette`，按 `BlackPalette / WhitePalette / DraculaPalette / SagePalette` 组织基础配色及应用专用的操作颜色；默认 Sage，选择跨启动保存。`PicNoteTheme` 统一提供颜色与系统栏明暗，页面、抽屉、编辑浮层和 Markdown 阅读随方案更新，图片内容保持不变。

创建文档操作使用 `ThemePalette.createDocument` 的前景色与背景色，通过 `CreateDocumentButton` 应用到抽屉“＋新建”。普通按钮继续使用 Material 3 颜色角色；后续实际需要的业务状态色在 PicNote 调色板中扩展。按钮沿用 agit 的高度与内容留白，图标按钮保持至少 54dp 高的交互区域。

| 项目 | 值 |
| --- | --- |
| 背景、面板、文字、操作色与细线 | 使用当前颜色方案对应的 Material 3 颜色角色 |
| 节点图片比例 / 圆角 | `4:3 / 12dp` |
| 纯文字节点 / 章节节点高度 | 固定 `72dp`，圆角 `12dp` |
| 图片备注层 | `32dp`，最多两行 |
| 编辑浮层距可用区域左右边距 | 各 `24dp` |
| 阴影建议值 | 垂直偏移 `10dp`，模糊约 `24dp`，透明度约 `18%` |
| 设置显隐时序 | `0.5s + 3s + 0.5s` |

阴影仅用于抬起完整图片，不作为图片内容滤镜；正文与普通卡片保持平静，避免增加装饰性状态面板。
