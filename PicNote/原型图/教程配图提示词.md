# 教程配图提示词

使用内置 `image_gen.imagegen` 编辑，两个语言分别以原有桌面图为编辑目标，以白底竹节笔 [01-bamboo-pen.png](../artwork/bambootes/01-bamboo-pen.png) 为标志参考。保留三列三行、米白桌面和占位图标，只替换正中的图标与名称。产物通过 `~/bin/pastehub-image` 调整为 512 × 640 并以质量 90 编码为 WebP，保存于 `PicNote/src/main/assets/welcome/zh-CN/launcher.webp` 和 `PicNote/src/main/assets/welcome/en/launcher.webp`。

## 简体中文版

```text
Use case: precise-object-edit / text-localization.
Image 1 is the EDIT TARGET: the existing compact Android home-screen tutorial image. Image 2 is the authoritative REFERENCE for the newly approved Bambootes app icon.
Edit Image 1 only in the CENTER app slot (row 2 column 2), and its label. Replace the old blue/slate stacked-photo app icon with the EXACT flat GREEN BAMBOO FOUNTAIN PEN symbol from Image 2 on a PURE WHITE (#FFFFFF) rounded-square icon tile. Copy the reference silhouette faithfully: diagonal bamboo pen pointing down-left, three bamboo joints, two leaves on the right, a split fountain-pen nib; green #257956, no added elements, no color gradient. Use the full pen and leaves from the reference, keep generous white padding, match the center icon's existing tile size.
Replace its app label with exactly "竹节笔记", four Chinese characters centered on one line, in the existing dark sans-serif type, same visual size. No old name remains.
Preserve EVERYTHING ELSE: exact portrait 4:5 composition, three columns and three rows (9 slots total), 8 empty grey rounded-square outlines with three grey dots below each, warm ivory desktop background, status bar 9:41, signal/battery, page dots, bottom gesture bar, positions, spacing and original clean flat style. Do not add a phone frame, text, arrows or watermarks.
Output one standalone tutorial image, 1024 x 1280 or another exact 4:5 size, intended to downsample to 512 x 640.
```
