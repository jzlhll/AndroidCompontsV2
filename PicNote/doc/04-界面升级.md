# 竹节笔记 / Bambootes · 04 界面升级

本文只写升级涉及的界面增量。页面骨架、Tab、抽屉、编辑页表单、主题切换、教程与导出沿用 `PicNote` 现有设计（[03-程序界面设计.md](../03-程序界面设计.md)、[05-节点设计.md](../05-节点设计.md)），不再重复。

## 1. 全局

- 首页仍是两 Tab（`节点 / 文档`），`HorizontalPager` 不分页滑动、只点 Tab 切换，标题栏 54dp 与 Tab 指示线 51dp 不变。
- 新增两个普通全屏目的地：`ParseLogRoute`（解析记录）与 `MemoryRoute`（记忆与偏好），沿用 220ms 横向进退动画与顶栏返回箭头。
- 入口：顶栏“⋯”菜单在导出之前新增“解析记录”；抽屉底部在“外观”“设置”之间新增“记忆与偏好”。
- 设置页在“语言”下新增“解析服务”，配置地址、模型与密钥。
- 解析期间不新增底部常驻工具栏，不改变 Tab 高度与滚动位置。

## 2. 节点页

### 2.1 解析条

图片卡片下方新增一行解析条，宽与卡片一致，高 48dp：

| 状态 | 左侧标签 | 右侧文字 |
| --- | --- | --- |
| `pending` | “待解析” | 无（整行留白） |
| `parsing` | 进度点 + “解析中”或“本轮排队” | 无 |
| `parsed` | “已解析” | 解析文字最多 2 行，超出省略 |
| `stale` | “待更新” | 旧解析文字最多 2 行 |
| `failed` | “失败 · 重试” | 无；整行可点，点击即重试该节点 |

- 标签 12sp，左侧圆点 6dp，标签底色为状态色 12% 透明、圆角 6dp，与卡片右上角类型标签同一视觉体系。
- 解析文字 14sp、行高 20dp、颜色 `onSurfaceVariant`，不做内部滚动，超出省略；完整内容在编辑页。
- 无图片的正文节点、标题、引言、章节标题不显示该行；`尚未解析` 不显示占位结论。
- 点击解析条等同点击卡片右上角编辑按钮，进入编辑页。

### 2.2 状态标记

状态只出现在解析条的标签与圆点上，不给整张卡片染色，不改变图片比例、圆角与卡片间距。左侧轴栏保持竹枝、编号与类型色不变，不新增状态图形。

批量提交后按链序自上而下依次变化，单节点提交成功即转“已解析”，不等整批结束。

### 2.3 底部操作

保留现有布局：左下新图框、右下相册 `＋` FAB。有待解析节点时，在 `＋` 左侧新增“解析 N”胶囊：

| 元素 | 尺寸与样式 |
| --- | --- |
| 解析胶囊 | 高 56dp，圆角 16dp，`secondaryContainer` 底，图标 + `解析 N`，`N` 为待解析与待更新数量之和 |
| 相册 FAB | 高 56dp，`primary` 底，图标 `＋` |
| 新图框 | 48dp 缩略图 + `新增N`，圆角 16dp，与解析胶囊间距 12dp |

- `N = 0` 时不显示解析胶囊；`N > 0` 且未配置解析服务时胶囊置灰，点击提示去设置。
- 解析进行中胶囊变为“解析中 1/3”，点击重新展开遮罩。
- 有待解析节点或解析胶囊显示时，节点页与文档页的 `bottomContentPadding` 由 96dp 提高到 144dp，避免遮挡末项。
- 教程文档不显示解析胶囊。

## 3. 提交遮罩

全屏 `Dialog`（`usePlatformDefaultWidth = false`），底色 `MaterialTheme.colorScheme.surface`，不使用固定白色面板，不使用模糊背景：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 右侧“收起”文字按钮；无关闭图标 |
| 进度 | 28dp 环形进度 + “已保存 1/3” + 阶段文案（读取图片 / 提取内容 / 组织文字） |
| 内容 | 已完成节点的解析文字流，14sp，`onSurfaceVariant`，可滚动；新结果出现时自动滚到底部 |
| 底部 | “停止解析”文字按钮（错误红）+ 已耗时 |

- “收起”或系统返回：遮罩关闭，任务继续；节点页解析胶囊恢复为“解析中 1/3”，点击再次展开。
- 点“停止解析”：弹 `AlertDialog`，标题“取消本次解析？”，正文“已保存的 1 个节点会保留，剩余 2 个回到待解析”，按钮“继续解析 / 取消解析”。
- 确认后按钮变为“正在停止…”，等待当前节点事务结束后关闭遮罩；等待期间禁止再次提交。
- 完成：关闭遮罩并提示“已解析 3 个节点”，不显示设置项、提交 ID、JSON 或工具字段。
- 遮罩不拦截状态栏与导航栏安全区，进入动画 200ms，关闭系统动画时直接切换。

## 4. 解析记录页

顶栏“解析记录”，列表按时间倒序：

| 行内容 | 说明 |
| --- | --- |
| 标题行 | “第 4 次解析 · 3 个节点” |
| 副行 | 时间、状态（完成 / 中断 / 失败）、已保存 2/3 |
| 展开 | 节点编号与状态、“查看输入快照”“查看事件原文”两个折叠区 |

- 输入快照与事件原文用等宽小字只读展示，最多 200 行后提示已截断；不含密钥与图片 base64，图片以“图片 2 张”形式提示。
- 空态显示“还没有解析记录”。
- 该页为只读回放，不提供重试或取消；重试入口在节点页。

## 5. 记忆与偏好页

顶栏“记忆与偏好”，三组，均使用现有 Material 3 列表与单选样式：

| 分组 | 内容 |
| --- | --- |
| 写作偏好 | 语言（跟随系统 / 中文 / English）、结构（大纲 / 段落）、术语（保留原文 / 中文意译）、篇幅（简短 / 标准 / 详细）；单选即时保存 |
| 当前文档记忆 | 已覆盖节点数、最近整理时间、待更新节点数；“重新整理”按钮 |
| 说明 | 一段说明：解析只发送本批素材与本章上下文，不含其它文档 |

- “重新整理”触发分段重建，进行中禁用并显示进度，失败提示可重试，不影响节点状态与正文。
- 不提供 OCR 开关、模型包下载、向量库设置，也不提供跨文档引用入口。
- 有活跃轮次时可以查看与修改偏好，修改只影响之后的批次。

## 6. 编辑页

在现有 `EditorScreen` 的正文节点（`body` 且有图片）中，文字输入框下方新增“解析”区块：

1. 标题行：状态标签 + 右侧“重新解析”文字按钮（解析中或本轮锁定时隐藏）。
2. 多行输入框：初值为 `parsed_markdown`，可编辑；保存后写入并标记 `origin = user`。
3. “精细识别”开关行：说明“公式、代码、表格优先保持分辨率”；切换后节点转“待更新”。
4. 活跃轮次中该节点只读，显示“本轮结束后可编辑”与进度入口。

其余字段、顶栏按钮、图片上下移与替换移除、删除确认全部沿用现有编辑页。

## 7. 状态色

`ThemePalette` 新增四组状态色，仅用于解析条标签、圆点与遮罩进度；背景统一取同色 12% 透明，不新增独立底色：

| 主题 | 待解析 | 解析中 | 已解析 | 失败 |
| --- | --- | --- | --- | --- |
| Black | `#F0C674` | `#7DB4F0` | `#86E3A8` | `#F08C7C` |
| White | `#8A5A00` | `#1D4ED8` | `#166534` | `#B42318` |
| Dracula | `#FFB86C` | `#8BE9FD` | `#50FA7B` | `#FF7A85` |
| Sage | `#8A5B1F` | `#365F82` | `#2F6B45` | `#9E3B2F` |
| Alucard | `#846E15` | `#036A96` | `#14710A` | `#9E2B2B` |

“待更新”复用“待解析”色，文案不同。节点类型色、引言灰字、卡片底色与五套基础配色保持不变。

## 8. 尺寸表

| 项目 | 值 |
| --- | --- |
| 解析条 | 高 `48dp`，文字 `14sp/20dp`，最多 2 行 |
| 解析标签 | `12sp`，圆角 `6dp`，圆点 `6dp` |
| 解析胶囊 | 高 `56dp`，圆角 `16dp` |
| 底部内容留白 | 有解析入口时 `144dp`，否则沿用 `96dp` |
| 遮罩进度环 | `28dp` |
| 遮罩进出动画 | `200ms` |

## 9. 文案

| 场景 | 文案 |
| --- | --- |
| 待解析 | 待解析 |
| 解析中 | 解析中 / 本轮排队 |
| 已解析 | 已解析 |
| 待更新 | 待更新 |
| 失败 | 失败 · 重试 |
| 提交按钮 | 解析 N |
| 取消确认 | 取消本次解析？ |
| 完成 | 已解析 N 个节点 |
| 未配置服务 | 请先在设置中配置解析服务 |
| 本轮锁定 | 本轮结束后可编辑 |

界面文字不出现协议名、提交 ID、字段名与“模型”以外的技术名词。
