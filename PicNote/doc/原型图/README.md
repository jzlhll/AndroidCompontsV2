# 竹节笔记 / Bambootes · 解析升级原型

首页导航为 `节点 / 文档 / 会话` 三个等宽 Tab。本目录三张静态原型仅展示前两个 Tab 的内容与 `EditorScreen` 的正文创建态；`会话` 承载当前文档的 LLM 实时 SSE 输出与历史轮次，详细设计见 [04-界面升级.md](../04-界面升级.md)。沿用实际 `SagePalette`、54dp 标题栏、51dp Tab 指示线、72dp 无图卡片、竹枝编号与 4:3 图片卡；中文文字直接由 SVG 渲染，PNG 均为 960 × 2312。

## 交互边界

- 首页保留 `节点 / 文档 / 会话` 三个等宽 Tab；`会话` 同时呈现当前文档进行中的 SSE 输出与历史轮次，节点创建使用独立全屏页面。
- 首页浮动操作分成两层：上层为解析胶囊，下层为待选区入口与相册 FAB；不把三个入口挤在同一水平行。示例仍有后续节点，列表底部需保留完整的双层浮动操作与系统栏滚动余量。
- `01-节点页.png` 展示没有活跃轮次的瞬间，`04` 节点已解析，屏幕下方还有待处理节点，因此显示“解析 2”；按钮计入 `pending / stale / failed`。备注修改本身不触发重新识图。
- `02-文档页.png` 展示另一个瞬间：当前浏览“摄影学习笔记”，全局正在解析“植物观察”。唯一进度胶囊在正文外标明“植物观察 · 解析中 1/3”，点击展开该任务；切换 Tab 或文档仍复用同一个入口，不另开解析。当前文档可编辑，任务所属文档在任务结束前只读。
- `03-新增节点.png` 已选好图片，因此展示精细识别。保存成功才把节点加入选定位置，有图片时进入 `pending`，保存不发起上传；返回放弃不产生空节点。没有图片时不显示精细识别，保留纯文字正文创建能力。
- 正文创建沿用“章节标题 / 正文”类型选择，不创建新的 `title / introduction`，也不新增独立起始节点。仅固定第 2 位的引言提供起始信息。
- 节点图片预览裁切为 4:3，文档页与创建页使用素材的原始 16:9。原型下方的说明文字位于手机外，仅用于解释设计。

## 重新生成

使用 [generate-prototypes.mjs](generate-prototypes.mjs)，需要 Node.js、`@resvg/resvg-js`、macOS 自带的 `sips` 和中文字体。脚本复用仓库内的 `node_bamboo_long_branch.webp`，经临时 PNG 转换后内嵌到 SVG，临时目录自动清理；其他示例图像为可重复生成的矢量素材，不联网读取图片，不修改包配置。

在仓库根目录执行：

```bash
npm install --prefix /tmp/picnote-upgrade-render --cache /tmp/picnote-upgrade-npm-cache --no-audit --no-fund @resvg/resvg-js@2.6.2
PICNOTE_RENDER_MODULE_ROOT=/tmp/picnote-upgrade-render/node_modules node PicNote/doc/原型图/generate-prototypes.mjs
```

示例使用 macOS 的 `Hiragino Sans GB`。其他系统请安装可用中文字体，并按环境调整脚本的 `font-family` 和 `defaultFontFamily`。

设计规则以 [04-界面升级.md](../04-界面升级.md)、[05-节点设计.md](../../05-节点设计.md) 与 [03-程序界面设计.md](../../03-程序界面设计.md) 为准。本目录仅提供原型和生成资源，不修改应用源码、数据库或媒体数据。
