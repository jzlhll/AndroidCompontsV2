# Studex · 03 程序界面设计

## 1. 全局结构

单 Activity，顶部仅文档标题、抽屉按钮与“⋯”，下方为 `节点 / 文档 / 会话` 三个 Tab，由 Compose Foundation `HorizontalPager` 承载，各页独立保存滚动位置。首页保持留白，不常驻更新时间、节点总数、标签和大面积状态底色。

左侧 navMenu 切换 `Session`，右上角固定“＋ 新建”；会话 Tab 回放当前文档的 `Turn`。顶栏“⋯”提供导出、同步文档顺序、重建文档与设置。

解析期间各 Tab 顶部保留一行“正在解析 · 本轮已保存 1/3”，点击展开遮罩。切到其他文档时改为“注意力机制正在解析 ›”，该文档提交禁用，点击返回任务所属文档。

## 2. 节点页

### 2.1 新建与起始信息

点击 navMenu 右上角“＋ 新建”，创建 `Session` 并进入节点页，默认生成第一个纯文字节点，用于填写起始信息。标题未设置时为“未命名文档”。

起始节点使用与图片卡相同的 4:3 外框，提示“这次想学什么？”，引导用户说明学习主题、正在观看的视频或文章，以及本篇文档预计记录的内容。点击“填写起始信息”进入编辑遮罩，输入可以是一段自由文字；允许稍后填写，不强制走创建表单。空白草稿不进入解析，填写后按 `pending` 处理。

首次提交使用已填写的起始信息建立文档前缀；后续轮次复用同一份用户文字，放在固定协议和写作偏好之后、动态章节与素材之前。前缀不被滚动摘要替换，修改仅影响之后的新轮次；历史请求快照保持原样。未填写时不生成虚构背景。

### 2.2 节点轴与插入

节点沿左侧细竖轴按链序排列，轴上圆点与右侧卡片的竖向中点对齐。点击圆点弹出就近的选择菜单，仅含“插入上一个节点”和“插入下一个节点”；点击外部关闭。

选定位置后创建草稿并打开编辑遮罩，可以填写文字或添加图片；保存后才写入指定位置，取消不留下空节点。批量选择图片时按选定位置插入；底部截图入口仍默认追加到链尾。运行中不开放前后插入，继续追加的素材进入下一轮。

无活跃轮次时保留长按 300ms 拖拽排序；删除放在编辑遮罩中，首页不铺开操作按钮。起始信息保留其节点身份，排序后仍按该节点引用建立前缀。

### 2.3 图片卡与备注

图片区宽高比固定为 **4:3**，高度等于卡片宽度 × 3/4。使用 `centerCrop`（Compose `ContentScale.Crop`）居中裁切铺满；小图允许放大变模糊，不缩成小块或产生留白。原图不被裁切覆盖，解析仍使用保存的原始素材及其压缩副本。

一个节点默认展示首张图；有多张图时在同一固定图片框内横向查看，不把首页拆成拼图。无图的纯文字节点沿用同尺寸浅色卡，展示文字或起始提示。

保存备注后，图片底部以 **32dp** 高的半透明渐变层承载文字，最多两行，超出用省略号；没有备注时不显示该层。

### 2.4 设置入口显隐

图片右上角设置按钮默认隐藏，不占据常驻视觉空间。单击图片后按以下时序显示：

1. 0.5 秒渐显。
2. 完全显示后停留 3 秒。
3. 0.5 秒渐隐。

再次单击时取消旧的隐藏 Job，从当前透明度显示并重新等待 3 秒；打开编辑遮罩或离开页面时取消计时。按钮可见时点击只打开编辑，不再次触发图片单击。关闭系统动画时直接切换透明度；无障碍提供常驻的“编辑节点”操作。

### 2.5 状态与模型内容

状态以轴上小圆点及卡片下方小字呈现，不把整张卡染色，不再额外堆放解析标题与标签。

| 状态 | 呈现 |
| --- | --- |
| `pending` | 黄褐色小字“待解析”；运行中新追加为“下一轮” |
| `parsing` | 蓝色小进度及“解析中 / 本轮排队”，保留锁标记 |
| `parsed` | 图片下方 **48dp** 高的模型文字区，以“已解析：”开头，可在区内独立竖向滚动 |
| `failed` | 红色“失败 · 重试”，点击只重试该节点 |

48dp 模型文字区滚动到边界后交回外层节点列表；用户备注仍留在图片的 32dp 渐变层，两者分别展示。解析期间本轮节点与既有已解析节点只读，新追加的下一轮节点可编辑、删除。

### 2.6 底部操作

底部使用一行轻量工具栏：左侧“新截图 N”展开截图纸带，右侧“解析 N”提交待处理节点。没有可提交素材时禁用；有活跃任务时显示“解析中 1/3”，点击可进入取消确认。不再使用悬浮在卡片上的 FAB。

截图纸带默认收起，展开后显示横向缩略图、勾选圈、“加载更早”和“追加 N 张”；运行中改为“追加到下一轮 N 张”。已在链上的截图不可重复选择；已复制的原图不受相册源删除影响。

## 3. 节点编辑遮罩

点击设置后在当前页面上展开全屏背景模糊遮罩；编辑内容左右各留 **32dp**，不再套一个窄小的居中弹窗。顶部固定关闭、标题“节点编辑”与“保存”，其余内容整体竖向滚动。

内容顺序固定为：

1. 原图：以可用宽度显示，按真实宽高比计算高度，完整展示，不裁切；长图继续向下滚动。多张图按顺序竖排。
2. 用户备注：可继续编辑的多行输入框；纯文字节点在此编辑正文，起始节点提示填写学习背景。
3. 解析状态：展示真实的“待解析 / 解析中 / 已解析 / 失败”，由实际任务和保存结果驱动。
4. 解析内容：已有模型结果时使用可编辑文本框，用户可直接修正；未产生结果时不生成占位结论。
5. 次要操作：添加或移除图片、保留图片细节、删除节点。

保存时比较实际变化：

- 只修正模型内容：保留 `parsed`，将修正文字作为用户确认的节点结果更新节点记忆，关联章节标记待更新；下次整理复用修正文字，不重新上传图片。
- 备注、原图或识图选项变化：回到 `pending`，旧模型文字保留供回看，但退出有效上下文，关联章节和记忆待更新。若同时修正模型文字，仍按素材变化回退。
- 无实际变化：直接关闭，不改变状态。

修改后关闭或系统返回时可放弃或继续编辑；保存成功返回链上原位置，备注进入 32dp 渐变层，模型内容进入 48dp 文字区。除自动创建的起始空草稿外，保存节点必须至少有一张图片或非空文字。

正在解析或活跃轮次中的已解析节点可打开同样的遮罩查看，输入区只读并显示“本轮结束后可编辑”及任务入口；下一轮节点可保存。手工修正不伪造 `parsing` 或本地解析提交成功事件。

## 4. 文档页

顶部信息显示字数、更新时间和有效来源数，提供复制与导出。文档有失效来源时显示“有 1 处内容待更新”；纯拖拽时显示“顺序待同步”及“同步文档顺序”按钮，此操作不重传历史图片。

正文建议 H1 24sp、H2 20sp、正文 15sp、行高 1.7，图片圆角 10dp，点击全屏；节末“来源 2 个节点 ›”跳回链并短暂高亮对应节点。来源用节点数，图片数量在详情展示。

流式候选区显示“正在整理，尚未保存”；正式正文只在本地提交组成功后更新。用户滚离当前章节后不自动拉回，提供“查看最新”入口。

## 5. 会话页

顶部切换“摘要视图 / 原文视图”，此切换只影响轮次回放，不是节点状态筛选。

轮次卡展示“第 3 轮 · 3 个节点”、时间、状态和已保存进度。摘要视图显示用户文字、本次图片数量、引用范围、模型结果及中断原因；原文视图显示实际请求清单和事件，鉴权信息不落档、不上屏。

本地图片以缩略图或本地引用展示，不把 base64 文本填满页面。被拒绝的协议事件在原文视图注明原因，不能显示为已采纳结果。

历史来源删除后，对应片段显示“来源已删除”；旧轮次不能作为当前有效记忆继续注入。

## 6. 解析遮罩、收起与取消

全屏半透明深色遮罩，内部白色进度面板。右上“收起”，内容为蓝色进度环、“本轮已保存 1/3”、阶段文案及滚动的自然语言候选文本；底部“停止解析”和耗时。

- 点击“收起”或系统返回：回到页面，任务继续。
- 顶部任务入口：重新展开同一遮罩。
- 点击底部“解析中 1/3”或“停止解析”：弹“取消本次解析？”。
- 取消确认：说明“已保存的 1 个节点会保留，剩余 2 个回到待解析”，按钮为“继续解析 / 取消解析”。
- 确认后显示“正在停止…”，等待当前本地提交完成，再回到链；不能在等待期间重复提交。
- 正常完成：关闭遮罩，提示“已解析 3 个节点，文档 +2 节”，可跳到第一个新保存节点；失败或取消使用实际提交数提示。

遮罩不显示 `append_section`、`commit_id`、JSON 或内部工具字段；这些只在会话原文中出现。

## 7. 文档抽屉

宽度约屏幕 86%，顶部左侧“我的文档”，右上角为“＋ 新建”。列表当前文档浅色高亮，每项只展示标题、节点数和简短时间；运行中的项增加一行“解析中 · 1/3”。行内菜单提供重命名、归档、删除，底部保留“已归档”及“记忆管理”。

全局只允许一个活跃 `Turn`。运行中文档可切离、可重命名，归档和删除需先停止任务；切换后的其他文档仍可浏览与追加截图，但不能提交。

删除确认写明原图、正文、轮次和记忆的范围，以及其他文档已有正文保留、引用副本会清理。新建后直接显示默认起始节点；历史引用不自动选择，可从记忆管理中手动添加。

## 8. 记忆管理

“写作偏好”展示语言、结构、术语要求；“当前文档记忆”展示节点覆盖、待更新来源和重新整理入口；“引用历史文档”展示用户选定的来源和章节，可预览、更新引用或移除。

“重新整理记忆”仅整理已有摘要，不重新识图或重写正文。历史来源更新显示“来源已更新”，删除则显示“来源已删除”；无效内容不进入新请求，界面不把旧引用当作已掌握知识。

有活跃轮次时可以查看；相关编辑、引用变更和重新整理需等轮次结束。不显示 OCR 开关、模型包下载或向量库设置。

## 9. 配色、尺寸与动效

| 语义 | 值 |
| --- | --- |
| 主操作 / 已解析 | `#2E7D5B` |
| 待解析 / 解析中 / 失败 | `#A66A00 / #4967D6 / #B74636` |
| 页面底 / 输入框 | `#FAFAF8 / #FFFFFF` |
| 主文字 / 次要文字 / 细线 | `#1F2926 / #697570 / #DFE6E1` |
| 图片比例 / 卡片圆角 | `4:3 / 12dp` |
| 备注层 / 模型文字区 | `32dp / 48dp` |
| 编辑内容左右留白 | 各 `32dp` |
| 设置显隐 | `0.5s 渐显 + 3s 停留 + 0.5s 渐隐` |

页面边距 16dp，节点轴和图片区之间留出间隔；状态色仅用于文字和小标记。交互热区至少 48dp，圆点与设置图标可保持小尺寸。解析遮罩收起约 200ms，关闭系统动画时直接切换。

## 10. 关键时序

提交：检查全局活跃任务 → 冻结待解析快照 → 节点置 `parsing` 并显示遮罩 → 预处理、打包、上传 → 暂存候选 → 本地提交成功 → 转绿并更新文档/记忆 → 完成或中断。

截图刷新：先显示本地待选缓存，再后台查询新图；重复刷新先取消并等待旧 Job，按已复制图片身份去重，禁止慢结果覆盖新列表。

捕获权限缺失时只影响截图捕获，允许浏览已有本地素材；具体 Android 权限和后台捕获能力在实现阶段按目标系统版本确认，不在原型中承诺常驻服务必然可用。
