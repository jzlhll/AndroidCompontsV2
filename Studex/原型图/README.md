# Studex 原型图

原型对应 [03-程序界面设计.md](../03-程序界面设计.md)、[04-灵感碎片.md](../04-灵感碎片.md) 和 [05-记忆系统设计.md](../05-记忆系统设计.md)。首版不做本地 OCR；图片直接交给模型，起始信息作为稳定前缀，后续记忆复用已解析摘要及用户修正。

[14-节点交互总览.png](14-节点交互总览.png) 展示本组相关交互：抽屉右上角新建、默认起始节点、简约节点页、圆点插入菜单、编辑遮罩及其滚动后状态。[00-原型总览.png](00-原型总览.png) 包含全部十三个界面状态。

其余 `02/03/04/05/08/09` 分别展示文档、轮次、解析遮罩、解析收起、记忆管理与取消确认。图中计数来自各自状态，不表示同一瞬间；静态 PNG 不承载可操作交互。

所有图片由 [generate-prototypes.mjs](generate-prototypes.mjs) 的矢量源生成。示例原图也由矢量绘制，列表裁切与编辑原图复用同一份内容，无外部图片依赖。单图分辨率为 960 × 1940，节点交互总览为 1536 × 2105，完整总览为 1536 × 5090。

在仓库根目录生成（需要 Node.js、npm 和中文字体；示例使用 macOS 的 `Hiragino Sans GB`）：

```bash
npm install --prefix /tmp/studex-prototype-render --cache /tmp/studex-prototype-npm-cache --no-audit --no-fund @resvg/resvg-js@2.6.2
STUDEX_RENDER_MODULE_ROOT=/tmp/studex-prototype-render/node_modules node todos/Studex/原型图/generate-prototypes.mjs
```

生成命令覆盖本目录的十五张 PNG。依赖安装在指定临时目录，不修改仓库包配置。
