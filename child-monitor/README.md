# 儿童监控

面向单个孩子的 Android 本地前台监控应用：录像与画面分析并发，自动校准后记录姿态、离开与返回、未知片段及提醒，停止后保存结算并支持历史回看。Android 10（API 29）及以上；录像无音轨，视频和观测不主动上传。

## 工程入口

Android Studio 打开 AndroidComponts 根目录，选择 `child-monitor` 应用模块；根 `settings.gradle` 将 `:child-monitor` 映射到本目录的 `androidApp`。也可单独打开本目录运行 `androidApp`，需保留完整仓库，供公共模块和根依赖目录引用。使用 JDK 17 和 Android SDK 37；具体工具链以构建配置及技术文档为准。
