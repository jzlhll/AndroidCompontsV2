# 固定语音资源

10 段提示音位于 `androidApp/src/main/assets/voice/`，使用普通话女声 `zh-CN-XiaoxiaoNeural`，语速为默认的 92%，音高不变。语气面向儿童日常提醒，不加入音乐或音效。

生成使用文档中列出的 Microsoft Edge 在线朗读方案（edge-tts 7.2.8）；应用内由 Media3 离线播放预先打包的文件，不调用在线 TTS。Edge 接口只控制音色、语速和音高，不使用 Azure 的专用情绪风格参数。

| 文件 | 文案 |
| --- | --- |
| reminder_head_down.m4a | 抬抬头，坐直一点哦 |
| reminder_head_tilt.m4a | 把小脑袋摆正一点哦 |
| reminder_body_lean.m4a | 身体坐正一点哦 |
| reminder_posture.m4a | 抬抬头，把身体和小脑袋摆正一点哦 |
| reminder_away.m4a | 离开座位有一会儿啦，记得回来哦 |
| reminder_unclear.m4a | 我看不清啦，请帮忙调整一下摄像头 |
| reminder_rest.m4a | 坐了有一会儿啦，可以起来活动一下 |
| reminder_interruption_locked.m4a | 本次监控已停止，请保持屏幕常亮后再开始 |
| reminder_interruption_generic.m4a | 本次监控已停止 |
| reminder_save_failed.m4a | 本次录像保存失败，请查看本次结果 |

格式为 AAC-LC / M4A、24 kHz、单声道、64 kbps；生成后以 -20 LUFS、-3 dBTP 为目标统一响度。短提示的实际测量值以文件为准。manifest 保存来源、音色、参数、工具版本、每段时长、音量测量值及 SHA-256。

## 重新生成

本机准备 Python 3.10 以上、uv 和 FFmpeg。在 child-monitor 目录执行：

```bash
uv run --with edge-tts==7.2.8 python tools/generate-voice.py
```

如果 FFmpeg 不在 PATH 中，追加 `--ffmpeg /实际路径/ffmpeg`。生成时需要网络，仅发送固定提醒文案。脚本以 `copy/catalog.json` 为文案来源，按 manifest 的音频 ID 生成；文案调整还需执行 `yarn mobile-copy:generate` 更新界面资源。

全部片段完成转码、音轨解码、非静音和不同片段哈希检查后，才替换应用资源并更新 manifest。生成服务或转码失败时保留原有资源。实际设备的提醒触发、音频焦点、扬声器音量和后台停止场景仍需在应用内验收。
