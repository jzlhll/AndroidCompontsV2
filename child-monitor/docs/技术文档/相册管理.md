# 儿童监控技术文档 V1 相册管理

[对应交互文档](../交互设计/相册管理.md) · [技术主文档](主.md)

AlbumScreen、PlaybackScreen 由单 Activity / Nav3 承载，使用 RecordViewModel 查询 MonitorRepository。访问及路由恢复须采集已释放、Idle/Stopped，家长保护另校验授权；UI 不扫描目录充当列表数据源。

## 网格、检索与分页

LazyVerticalGrid 固定三列，日期标题占满行，sessionId 为稳定 key。分页默认 30 条，按 startedWallUs 与 id 倒序组合游标；摘要只加载列表所需字段，封面在后台生成并缓存。查询失败保留旧内容，不假装空列表。

RecordFilter 的日期、状态和名称备注条件共用于分页、全选及刷新。全选只查询可删除 ID；刷新重读已加载范围并只验证已选 ID，不自动选中新记录。浏览位置与合法选择需保持；重建、删除和过滤后的锚点按验收场景检查。

待保存项打开结果处理保存问题，Saved 且实际可用才能播放，损坏或仅统计保留统计和错误说明。记录变更失效通知只触发重查，不成为数据真相。

## 删除与空间清理

AlbumKey 保存 cleanup、sourceResult、protectedId。清理进入时不默认选择，UI 和 Runtime 都排除受保护及运行会话；清理返回刷新实际空间，不自动开始或重试保存。来源结果已删除时废弃失效返回路径。

完整删除先释放对应播放器，持久化 delete 意图，删除主视频、暂存与封面，再事务清关联事实和 Session；仅删录像使用 purge_video 意图，保留统计、评价、名称备注和标记。两种操作与保存按会话互斥，不存在文件按已删处理。批量允许部分成功，失败项及意图保留，重启优先完成删除，避免已删内容复活。

成功后才从列表移除；删除当前详情时清除引用该 sessionId 的结果/播放 key 和失效清理来源，返回合法首页/相册栈。失败或取消不清理当前页，关联行级联约束以 Room Schema 为准。

## 视频播放与时间轴

PlaybackKey 只传 sessionId，返回来源由现有返回栈保留。播放前读取媒体状态并探测文件，可用时创建 ExoPlayer；PlayerSurface 展示画面，页面拥有播放器，应用 playbackRegistry 以 sessionId 与实例标识注册，供退出、删除和授权撤销释放。

时间轴读取持久 Event 和 RestWindow，按时间与 id 排序并筛选类型，不重新分析视频。FaceIncomplete 与 SceneChange 使用同一事件列表回看。事件位置 = startUs - videoOriginOffsetUs，超出媒体覆盖不开放跳转；seek 控制当前播放器，显示实际 currentPosition，不能将请求位置当完成位置，关键帧偏差按 D09 验收。

前台恢复订阅记录 revisionFlow 并重读；查询失败重读记录，播放器失败释放旧实例后重建。后台暂停，NavEntry 退出清监听、表面和注册；保存/删除任务继续由 Runtime 持有。反复结算与播放按同 sessionId 去重，不能循环堆栈或恢复已删除内容。

检索汇总、只删录像、导出和事件标记的约束见[扩展设计](../扩展设计/功能扩展.md)，返回与故障场景见[验收标准](../评审与验收/验收标准.md)。
