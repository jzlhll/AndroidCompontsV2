# 儿童监控技术文档 V1 更多设置

[对应交互文档](../交互设计/更多设置.md) · [技术主文档](主.md)

SettingsScreen 由 MonitorScreen 的 SettingsOverlay 承载，设置覆盖层不创建新 Activity 或独立设置路由；MonitorViewModel 收集 Runtime 快照，页面只组织草稿与操作结果。

## 访问与修改

SettingsAccess 与 Runtime 共用 canChangeSettings：Live 和 NextSession 项允许在 Preparing/Monitoring 修改；Stopped 项要求 captureReleased 及 Idle/Stopped，Starting/Stopping 或互斥操作期间不接受修改。只有录像中受 Stopped 策略限制的项目标记 `*`；开关依赖另给具体说明。暗屏等待、默认恢复、清理及相机检查保持停录限制，重新校准仍走独立 reposition。

## 数据归属

| 设置项 | 持久化位置与操作 |
| --- | --- |
| 检测开关、灵敏度、确认时间、离座允许时长 | Room MonitorSettings，updateSettings |
| 声音、音量、提醒间隔、久坐提醒、目标与自动结束 | Room MonitorSettings，updateSettings |
| 头像、暗屏等待、录像保留期 | DataStore UserPreferences，updatePreferences |
| 家长 PIN 与失败冷却 | ParentAccess 独立 DataStore；授权只在内存 |
| 存储信息 | 实时读取持久目录和设备空间，不另建配置副本 |
| 默认恢复、帮助与版本 | 默认恢复仅替换 MonitorSettings；帮助与版本不写会话事实 |

Room 与 DataStore 版本独立。updateSettings 接收完整 MonitorSettings 和 expectedRevision，页面从当前快照复制并只修改目标字段；updatePreferences 使用字段 patch 和 preferencesRevision。冲突或失败保留原持久值并重读，不能写默认配置掩盖读取失败。

UiSnapshot.settings 保存全局配置，sessionSettings 保存本次生效配置。开始时固定目标时长与自动停止策略，录像中修改这两项只更新全局配置；其他 MonitorSettings 更新本次生效配置。updatePreferences 允许修改头像与保留期，包含 darkenAfterMs 的 patch 则必须停录。

动态配置由 Runtime mutex 串行处理；Room 事务一次提交全局版本、ConfigRevision 和旧配置事实，提交成功后才切换检测器内存状态。已确认事件跨版本分段，连续事件沿用 logicalEventId；受影响项目重新确认，其他项目保留计时与校准。帧时间早于新配置生效时间的排队观测不再用新规则处理，历史事件与评价不被新设置覆盖。

关闭检测或改变条件时取消已失效提醒，声音关闭同时取消行为提醒和试听；音量从后续播放生效。规则切换不触碰 CameraX 绑定、模型或编码器。默认值与校验见[交互主文档](../交互设计/主.md#初始参数)。

## 生命周期

SettingsPage 在首页 Box 内切换设置、头像和存储内容，SettingsOverlay 始终叠加在主界面组合树上；不通过 NavDisplay 替换首页。关闭设置恢复首页，保持同一预览和采集链路。头像保存返回时通过快照刷新，未保存返回不改持久值。界面重组不发起写入，已接受的 Runtime 操作不依赖面板生命周期；页面清理自己的订阅和草稿。
