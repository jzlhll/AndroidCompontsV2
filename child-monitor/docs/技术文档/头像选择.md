# 儿童监控技术文档 V1 头像选择

[对应交互文档](../交互设计/头像选择.md) · [技术主文档](主.md)

AvatarScreen 使用 MonitorViewModel 的 Runtime 快照；首页入口使用 AvatarKey，设置入口使用覆盖层内的 SettingsPage.Avatar。覆盖层路径保留首页的 PreviewView 和采集生命周期，Preparing/Monitoring 允许保存头像；Starting/Stopping 和互斥操作期间禁止保存。家长保护开启时检查授权。

## 资源与草稿

AvatarCatalog 定义稳定 id 和默认项，Android drawable 打包内置头像，AvatarResources 映射资源。只选择内置头像，不申请相册或拍照权限；未知 id 显示默认头像，不将显示回退写回覆盖持久值。

selectedAvatarId 作为页面草稿独立于 UserPreferences，选中只更新预览，未保存返回不改变全局值。页面重建使用可保存状态；默认头像首次启动即可用。

## 保存与返回

调用 updatePreferences(UserPreferencesPatch(avatarId), preferencesRevision, requestId)，校验头像与独立偏好版本，DataStore 原子更新不覆盖暗屏、保留期或 Room 配置。成功后返回来源，首页和设置由 Runtime 快照刷新；失败保留草稿并重读或重试，不伪报保存成功。

保存中禁止重复提交和返回，读取失败不能用默认头像当作读取成功。已接受持久化由 Runtime 应用作用域完成，页面只拥有草稿及订阅。
