# 儿童监控技术文档 V1 本次结算

[对应交互文档](../交互设计/本次结算.md) · [技术主文档](主.md)

ResultScreen 由 ResultKey(sessionId, celebrate) 打开，使用 RecordViewModel 从 MonitorRepository 读取持久 Result，不复制前页内存统计。正常停止后、首页中断卡、待保存记录和视频详情共用结果页；记录不存在时清理失效导航，不新建空结算，查询失败提供重试。

## 统计与反馈

EvaluationEngine 生成带规则版本的评价快照，超过 3 分钟进入等级或完成型评价，否则仅展示小结。页面映射等级、数据不足说明、分项统计、中断原因与媒体状态，不参与评分；保存重试、记录刷新和历史回看不重算已持久快照。

正常结束、超过 3 分钟且首次符合展示条件才领取礼花；celebrationShown 持久化防止页面重建或回看重复。保存失败、中断和历史回看不自动播放，按钮不等待动画结束。建议来自已记录项目，不将未知、休息或设备问题解释成孩子表现差。

## 保存与失败处理

正式 VideoOutput + MediaCodec / MediaMuxer 完成编码关闭，RecordCoordinator 验证暂存媒体、移动最终文件并提交媒体状态。只在文件可验证且数据库提交后声明 Saved；一个会话一个逻辑视频，不承诺修复损坏 MP4。

| 保存态 | 页面及恢复处理 |
| --- | --- |
| Finalizing | 显示保存中，禁止重复操作 |
| Saved | 可用才开放录像、导出和仅删录像 |
| RetryableFailure | 有可验证源，提供重试、清理、稍后与放弃 |
| Unrecoverable | 明确录像不可恢复，保留统计或放弃，不提供虚假重试 |
| MetadataOnly | 无录像，统计和事件仍可读 |

重试走 Runtime 应用级许可，同会话文件操作互斥，采集未释放不得重试或新开始；重复请求不并行保存。只补未完成阶段，不重新录像、计时或评分。停止最终事实未提交时优先补交内存事实；进程恢复从可靠检查点补未知尾段后生成缺失评价。

默认等待上限 30 秒，超时给出失败出口；未完成封装的文件不能因存在就标可恢复，旧回调按 generation 隔离。文件移动后数据库失败复用同一 sessionId 补提交；封面失败不拖累主视频。详细检查点、清单和删除顺序见[数据与恢复](主.md#数据文件与恢复)。

## 操作与返回

待保存可稍后处理，已接受保存不因离开页面取消，进程终止后的恢复依靠持久记录。清理使用 protectedId 保护本次，返回仅刷新空间，由用户重试；放弃先确认并走完整删除。完全无内容只返回首页，不制造待保存记录。

查看录像仅对 Saved 且可用媒体开放。相同 sessionId 的结果与播放避免循环堆栈，删除后移除全部引用该记录的 key，不能返回已删结算。前台订阅记录失效并重查，查询失败与播放器失败分别处理；导出和统计卡片边界见[扩展设计](../扩展设计/功能扩展.md)。
