# 儿童监控交互设计 V1 更多设置

[返回主文档](主.md)

## 入口与访问条件

从首页设置按钮打开统一设置覆盖层，更多配置与检测参数使用同一面板。准备定位和监控期间可调整检测与提醒参数；启动、停止或互斥操作期间等待操作完成。只有必须停止录像的项目标记 `*`，点击提示先停录。依赖其他开关的项目置灰并说明需开启的功能，不标星。

头像与存储设置在同一覆盖层内打开，返回恢复设置列表；首页预览、录像和计时持续运行。

## 页面与配置

顶部提供关闭按钮与设置标题，主体以设置项列表展示额外配置。

| 设置项 | 展示与操作 |
| --- | --- |
| 检测开关、灵敏度、确认时间、允许离座时长 | 当前监控生效；修改规则仅重新计时受影响的检测项，保留其他检测和校准 |
| 头像 | 显示当前卡通头像，点击进入[头像选择](头像选择.md) |
| 暗屏设置 | 停止并释放采集后调整，默认 60 秒；应用内暗屏仍持续监控，触摸可唤醒 |
| 久坐休息提醒 | 开关 + 触发时长（默认开启、30 分钟）；连续在座达阈值时提醒活动，不计为异常，不影响评价等级 |
| 提醒音量与试听 | 录像中可修改与试听；音量从下一次播放生效，关闭声音停止当前播放；系统媒体音量较低时提示 |
| 目标时长与自动停止 | 0 表示不限，或填写 1～480 分钟；录像中可保存，下次监控生效，本次继续使用开始时的目标 |
| 存储管理 | 录像中可查看和修改保留期限，默认不清理，可选 7/30/90 天，下次清理生效；管理和批量清理须停录 |
| 家长 PIN | 可选 6 位 PIN，保护设置与历史操作；同一前台会话内有效，离开应用后重新验证 |
| 恢复默认监控参数 | 须停录，确认后还原检测、声音、提醒和目标参数，保留头像、偏好和历史 |
| 相机能力检查 | 调试版本提供；须停止并释放采集后进入 |
| 帮助与版本 | 定位、光线/遮挡、后台结束、本地数据说明及版本号 |

参数默认值与校验规则以[主文档](主.md#初始参数)为准，不展示尚无功能的配置入口。开关和选项即时保存；目标时长、PIN 等文本输入确认后保存，不新增保存页。启用自动清理和关闭家长保护需要明确确认。停止监控不要求 PIN。

动态修改只更新规则和偏好，不重新加载模型或重新绑定摄像头；需要改变模型或采集链路的配置必须在停录后操作。

## 返回

关闭覆盖层返回首页；运行中不改变录像和计时，停止后不自动开始。修改头像返回本页后更新头像展示。
