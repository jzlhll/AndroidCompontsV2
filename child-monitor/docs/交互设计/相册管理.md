# 儿童监控交互设计 V1 相册管理

[返回主文档](主.md)

## 入口与访问条件

从首页左上角相册按钮进入。仅在未开始或已停止监控时可访问；启动中、准备定位、监控中和停止中点击入口，提示「请先停止监控，再进入相册」。

## 视频网格与管理

相册采用每行 3 个视频、共 3 列的网格，向下滚动浏览；按监控开始时间倒序排列，可按日期分组。每个格子展示视频缩略图和时长，中断或录像异常使用简短标识，完整统计与评价放在视频播放页。一个视频代表一次监控，不将异常拆成多个视频。无记录时显示「暂无监控记录」。

顶部提供返回和「管理」。普通模式点击视频进入[视频播放](#视频播放)，「待保存」记录则进入[本次结算](本次结算.md#保存失败处理)处理保存问题；点击管理或长按视频进入选择模式，可多选、全选和取消选择，底部显示「删除」与已选数量。视频播放页也提供删除当前视频的入口。

删除前提示「删除所选视频及关联监控记录？」。确认后同步清理对应视频与关联数据库记录，包括事件、提醒及评价；失败时保留失败项并提示重试。删除当前播放的视频后返回相册，列表及时更新。删除仅在监控停止状态下操作。

## 从空间不足提示进入

首页或结算页点击「去清理」时，直接进入管理模式，默认不选中任何视频。本次待恢复记录显示「待保存」，不参与此次选择或全选，避免误删可恢复内容；用户如需放弃该次记录，回结算页使用明确的放弃操作。

删除后留在管理模式，可继续选择；点击「完成清理」回到发起清理的首页或结算页，重新检查空间。取消或返回同样回到原入口。无记录可删时显示「暂无可清理的监控记录」，提供返回操作。清理完成不自动开始监控或重试保存。

## 视频播放

从相册的视频网格点击视频，或从[本次结算](本次结算.md)点击「查看录像」，进入对应视频的播放页。仅在监控停止后访问。

页面包含播放器、本次评价与统计、异常时间轴和事件列表。时间轴可筛选低头 / 前倾、偏头、身体侧倾、人脸不完整、场景变化、离座 / 回座、建议休息、识别不确定及中断；点击事件跳转到对应录像位置。

视频不可播放时仍可查看记录及评价，并明确说明录像不可用；不存在可用视频位置的事件不提供跳转。

可再次查看[本次结算](本次结算.md)。统计口径和等级规则统一见[主文档](主.md#7-评价规则)。播放页提供删除当前视频的入口，沿用上述删除确认、关联记录清理和失败反馈，删除成功后返回相册。

## 返回

退出选择模式恢复普通浏览；从相册返回首页，保持监控停止状态。

视频播放页普通返回回到进入前的页面：从相册进入则返回相册并保留浏览位置，从本次结算进入则返回本次结算，不自动开始监控。

删除成功是普通返回规则的明确例外：无论从相册还是结算进入播放，删除当前视频及关联记录后都回到相册，并移除引用该记录的播放页和结算页。继续返回只能到首页，不能重新显示已删除的结算。删除取消或失败则保留当前页，普通返回路径不变。

## 检索、汇总与导出

相册可按日历日期范围、正常结束/中断/待保存/仅统计状态及名称备注筛选；分页和全选遵守当前筛选条件。记录详情可修改名称与备注。

从相册进入每日汇总与趋势，可查看近 7/30/90 天各日时长、有效覆盖、离座及姿态异常占比。各分项单日有效样本不足 10 分钟时不显示比例，不将未知补为正常。

结果页可通过系统文档选择器导出完整录像，或分享本机生成的不含录像的统计卡片。事件列表支持误报/无法判断标记及备注，标记不改原始评价。

管理模式及结果页提供「只删除录像，保留统计」，确认后仅移除已保存的媒体和封面；仅统计记录仍可打开事件列表。删除整条记录仍沿用原有完整清理语义。

家长保护开启后，相册、详情及删除/导出需验证；授权失效同时隐藏页面和弹窗，已接受的系统导出可继续完成。
