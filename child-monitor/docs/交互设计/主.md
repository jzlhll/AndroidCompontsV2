# 儿童监控交互设计 V1

本文定义单个孩子的本地前台监控、默认参数与评价规则。先读首页闭环，再按需要进入相册、结算、设置与头像子文档；工程和实现边界见[技术文档](../技术文档/主.md)。

## 1. 使用范围

应用无需登录，录像与实时分析并发，录像只保存画面、不收录麦克风声音。单次监控关联录像、事件、提醒和评价，可从事件定位回看。录像最高 480p 范围，分析最低 640×480；能力不满足时说明原因并阻止开始。

只在前台监控，运行时保持屏幕常亮；应用内暗屏继续采集。系统锁屏、息屏、切后台或核心采集故障结束本次监控并保存可用内容。不提供暂停、云同步、多孩子档案、身份识别、健康诊断或专注度推断。

## 2. 首页与页面结构

启动直接显示首页：相册入口、设置入口、默认卡通头像与画笔、本次时长和开始按钮。停止后保留本次时长，下次成功开始归零。

| 页面或面板 | 入口与访问条件 |
| --- | --- |
| 首页 | 启动应用；监控期间展示预览、状态、时长和停止按钮 |
| [设置覆盖层](更多设置.md) | 首页右上角；检测和提醒可动态修改，停录项单独标记 |
| [相册与视频播放](相册管理.md) | 首页相册、结算中的查看录像；须停止并释放采集 |
| [修改头像](头像选择.md) | 首页独立页面须停录；设置覆盖层内可动态修改 |
| [本次结算](本次结算.md) | 正常停止后、首页中断卡、待保存记录或视频详情 |

预览显示完整画面，不按头像圆形裁切。画面存在不等于识别有效，未知时仍录像和计时，但不补为正常姿态。相册、播放与批量清理受限时提示先停止；头像和存储设置在覆盖层内打开，不自动停止录像。

## 3. 开始、停止与暗屏

### 运行状态与转换

| 状态 | 主要行为与出口 |
| --- | --- |
| 未开始或已停止 | 头像、开始按钮；只有资源已释放且无互斥操作时可开始 |
| 启动中 | 检查权限、空间、前摄和模型；禁止重复开始，可直接取消 |
| 准备定位 | 录像与计时已开始，展示自动校准原因和进度；可确认停止 |
| 监控中 | 连续检测、提醒、暗屏；可重新校准或确认停止 |
| 停止中 | 固定业务终点，结束采集并保存；禁止重复操作 |
| 资源未释放 | 禁止再次开始，提示退出后重试；结果访问及迟到释放恢复出口见[待确认事项 D08](../评审与验收/设计约束与待确认事项.md) |

采集启动上限默认 15 秒，不包含等待系统权限。取消和超时后的迟到回调不能重新开始。首个实际写入的视频样本定义本次计时起点；真正录到的内容按同一记录保存，无内容时不创建虚假录像。

停止保存等待默认 30 秒，超时给出明确失败和后续操作，不无限加载。保存重试不重新录像、不累计本次时长；采集未确认释放不能开始新会话。

### 开始与准备定位

点击开始申请 CAMERA 权限，检查存储与采集组合；拒绝时说明用途，再次无法弹系统授权时提供系统设置入口，返回后重新检查。

固定设备，让单个孩子的完整人脸、双肩和足够上半身入镜，保持正常姿态约 3 秒自动校准，无需框选座位或采集空座位。界面提示光线、多人、脸部过小、半脸或贴边、双肩和姿态问题，连续有效样本中断后重新积累；明显歪斜或不完整证据不能作为正常基准。

准备阶段保留录像、总时长和停止入口，不进入暗屏、不记姿态异常或尚未建立的离座。准备默认超过 120 秒仍未完成则停止并保留结果。

设备移动或坐姿基准失效时提示重新校准。重新校准沿用同一会话和录像，清除旧人物、场景和休息许可，新基准只解释之后的样本；已经开始的连续无效截止时间不因点击操作而延长。

### 正常停止

准备或监控中点击停止、无设置面板时按返回，先确认；停止不要求 PIN，启动取消直接执行。接受停止后立即固定终点、闭合事件、取消待播行为提醒并请求结束录像，保存结果明确后进入[本次结算](本次结算.md)。

### 暗屏模式

监控中默认闲置 60 秒进入黑色覆盖层和低窗口亮度，保留运行提示，录像与分析继续。首次触摸只唤醒，不能穿透触发按钮；退出暗屏、结束或离开前台恢复原亮度。准备和需操作的持续无效提示期间不自动暗屏。

### 系统中断

锁屏或息屏按最高优先调度固定提醒并立即停止；后台、相机故障、写入失败或持续无效同样走单次停止与保存。语音尽力播放，不等待播完才保存，也不保证系统必定允许播放。

回到首页显示原因、已记录时长和保存状态，保存结果明确后开放查看本次结果。关闭提示只隐藏卡片，记录仍可在相册查看；不自动重新监控。进程异常恢复只认可靠检查点，缺失尾段记为未知。

## 4. 检测、离开与建议休息

### 检测项目

| 项目 | 记录与边界 |
| --- | --- |
| 低头或明显前倾 | 相对校准的头肩和人脸角度证据；持续默认 5 秒确认，正常短暂读写不直接判异常 |
| 偏头 | 头肩与人脸角度持续偏离；持续默认 5 秒确认，需真实转头样本核验误判 |
| 身体侧倾 | 肩线与可信躯干相对基准偏移；证据不足时该项目未知 |
| 人脸不完整 | 人体可见但半脸、贴边、轮廓缺失或脸部不可见，立即提示，持续约 3 秒记录 FaceIncomplete，复用姿态提醒 |
| 场景变化 | 非人体物体出现、消失、移动或背景持续变化约 3 秒，记录 SceneChange；完整人脸可见时接纳已确认新基准 |
| 离开与返回 | 联合人物、人脸、肩部及全画面变化确认，不能只凭无人检出判断离开 |
| 识别不确定与中断 | 记录独立区间或时间点和原因，不当作正常姿态或孩子表现差 |

FaceIncomplete 与 SceneChange 可在时间轴回看，不新增姿态评分分项，不推断孩子在做什么。低头、偏头、侧倾独立记录可判断时长；总姿态异常取区间并集，同一逻辑事件只计一次。

### 入座、离开与返回

自动校准完成建立首次在座。已在座后，人物、脸部与有效肩部都不可见，且原人物区域明显变化、其余背景稳定、没有新增或移动物体干扰，才累积离开候选；默认 3 秒确认后回填起点。单次漏检、遮挡、多人、弱光和无法解释的场景变化记未知。

确认离开后仅对可靠片段计时；未知区间不补时长，恢复同一离开事实不重复计次。人物回到画面仍需完整人脸持续约 2 秒才能确认返回。应用不识别身份，也不能承诺仅凭画面区分真实回座与经过画面，效果按标注样本验收。

### 持续无效与重新定位

普通无效持续 10 秒提醒看不清，30 秒恢复亮度并显示调整提示，120 秒停止；没有模型回调时仍推进超时。多人干扰提示原因，消除干扰后可稳定恢复；设备移动需人工重新校准。普通有效识别稳定 3 秒后清零无效计时，点击重新校准本身不清零。可靠离开属于有效观测，不启动无效超时。

### 久坐休息提醒与建议休息

连续可靠在座默认 30 分钟提醒一次活动。声音开启时按实际开始播放、关闭时按可见提示建立许可；失败且未展示不建立许可。在默认 2 分钟响应窗口内开始离开，前最多 3 分钟的实际可靠离开记建议休息，不计离开惩罚；候选确认跨过截止点仍按候选起点判断。

休息结束仍未返回，从普通离开起点重新计算允许时长。Unknown、重新校准或中断破坏连续在座与许可，不补发过期提醒，不虚增在座时长。

### 离座分类与分段计时

短暂普通离座默认不超过 2 分钟不计超时。每次监控首次普通离座不超过 3 分钟享有一次合理额度，超过该额度才计超时；后续按当段配置中的允许时长判断。建议休息从普通离座中扣除，未知不计入。

同一连续离座最多一次超时，使用严格“超过”判断。提醒与评价阈值独立：首次仍按允许离座时长提醒，不因合理额度延后提醒。展示离座、评级分母与覆盖率的详细金样待确认，见[评审事项 D07](../评审与验收/设计约束与待确认事项.md)。

## 5. 记录与回看入口

### 记录内容

每次监控保留录像、起止时间与时长、入座与回座时间、姿态异常与离座区间、建议休息、识别不确定、提醒和结束评价。录像期间参数只读，历史评价不因之后调参自动变化。

录像不可用时仍展示已保存的统计，明确说明视频状态。

### 存储不足的操作出口

启动前发现空间不足，结束启动中状态，在首页显示「存储空间不足，请清理后重试」，提供「去清理」和「暂不处理」。「去清理」进入[相册管理](相册管理.md)的管理模式，默认不勾选视频；删除后返回首页重新检查空间，空间足够时恢复可开始状态，由用户手动开始。

监控期间空间不足以继续录制时，先停止并保存已有结果，不在运行中跳转相册。采集结束后，首页中断提示卡或结算页显示「去清理」，再进入相册管理。清理返回后更新空间及保存状态，不自动重新监控；若本次录像仍可重试保存，则回到原结果页提供「重试保存」。

没有可删除记录或清理后仍不足时，保留空间不足说明，并提示清理设备其他文件后返回重试；用户可选择暂不处理。不得自动删除历史视频或默认选中待恢复的本次记录。

### 二级页面

[相册管理](相册管理.md)统一说明三列视频网格、选择与删除、视频播放、事件时间轴及评价回看。删除视频需同步清理关联监控记录，具体交互见相册管理文档。

## 6. 悬浮设置与提醒

右上角设置按钮打开首页内统一覆盖层，提供检测开关、确认时间、灵敏度、声音与音量、目标时长、暗屏、久坐提醒及存储和家长保护入口，详见[更多设置](更多设置.md)。关闭或返回恢复首页，不改变录像与计时。

准备和监控阶段允许动态调整检测开关、灵敏度、确认时间、离座时长和提醒参数；头像与保留期可修改，目标时长与自动停止下次监控生效。暗屏等待、相机检查、清理与默认恢复须停录，标记 `*` 并给出提示；启动、停止和互斥操作期间等待完成。重新校准仅在准备和监控阶段可用，沿用当前会话与录像。

设置保存成功才更新回显；动态检测规则只作用于生效时间之后，受影响项目重新计时，未改项目继续，不重算历史事件或评价。声音和提醒间隔不改变已有统计。动态调整不重载模型、不重绑相机；需要改变采集链路的配置须停录。

### 提醒调度与语音接入

行为事件与提醒调度分离，语音播放接收提醒类型和固定资源，不重新判定动作。首版内置固定语音音频，覆盖低头 / 前倾、偏头、身体侧倾、离座超时、看不清、休息及锁屏提醒，配合同内容的界面提示，暗屏时也能听懂要做什么。资源维护见[语音资源](../技术文档/语音资源.md)。

优先顺序为：监控中断 / 保存故障 → 持续识别不确定 → 离座超时 → 姿态异常 → 久坐休息提醒。同一时刻只播放一条，同等级姿态提醒合并成一句；高优先中断取消普通提醒。离座状态不播放坐姿提示，停止后取消过期提醒。

每个事件首次达到提醒条件时触发；持续不恢复时按提醒间隔重试，并设置全局播报间隔，避免多个事件轮流连续说话。事件恢复、失去可靠识别或条件失效后，未播放的提醒取消。播报失败不影响录像和检测。

提醒时间点单独保存，触发次数、成功播报次数和行为次数分别统计。声音关闭不阻止记录和视觉提示；最高优先级不意味着绕过用户静音或系统音量限制。

| 平台可知原因 | 界面与语音 |
| --- | --- |
| 锁屏 / 息屏（原因明确） | 「本次监控已停止，请保持屏幕常亮后再开始」 |
| 后台 / 相机中断（原因不明确） | 「本次监控已停止」 |
| 保存故障 | 「本次录像保存失败，请查看本次结果」 |

系统锁屏与后台属系统行为，结算页应明确说明不计入孩子表现。

## 7. 评价规则

结算页面布局、鼓励文案和返回操作见[本次结算](本次结算.md)。本节统一定义评价范围与统计口径。

### 评价范围与配置

以一次成功启动到本次停止或中断为一个统计区间，准备定位、监控、重新定位和建议休息均属于本次。本次时长自「首个实际写入的录像样本」起算至业务终点（endedOffset）；启动中（权限申请与相机启动等待）不计入；准备定位计入并单独标注为准备时间。超过 3 分钟必定生成本次评价；不超过 3 分钟保留录像和小结。

重新校准不取消评价、不拆成多次启动；录像期间参数不可修改。本次统计使用持久化的配置与事实，历史快照不因后续修改设置而重算。提醒声音、间隔或暗屏设置不影响已有统计。

评价包含鼓励反馈、可用行为统计和数据情况。有足够行为依据时显示 Great、Good 或 NotBad；缺失的检测数据不填成零异常，也不当作表现差。覆盖较少时照常给出本次评价，但按有效覆盖率门槛封顶等级，并标注「基于已识别片段」；完全没有可判断的行为数据时，给出「完成啦，坚持了 X 分钟」的完成型评价和调整设备建议，不虚构姿态等级。数据情况用于说明评价依据，不再作为取消本次评价的门槛。

### 统计与等级规则

判档前先做最小样本校验，避免有效样本过少导致折算失真：

| 校验项 | 门槛 | 不满足时处理 |
| --- | --- | --- |
| 分项有效在座检测时长 | ≥10 分钟 | 不做每 30 分钟折算，按绝对次数判档：Great ≤1 次、Good ≤2 次 |
| 在座比例分母（参与评级的在座 + 普通离座） | ≥5 分钟 | 在座比例标记「依据不足」，不参与判档 |
| 在座时长为 0 且普通离座 > 0 | — | 在座比例输出「不适用」，只用超时离座频率与姿态分项判档 |
| 超时离座频率分母（参与评级的在座 + 普通离座） | ≥20 分钟 | 不折算，按绝对次数判档：Great 0 次、Good ≤1 次 |
| 全部行为指标均不满足上述行为门槛 | — | 采用完成型评价，不虚构等级 |
| 有效覆盖率（可靠在座与普通离座的并集）÷ 本次时长 | ≥50% | [20%, 50%) 最高只能 Good；<20% 只能 NotBad 或完成型评价；均标注「基于已识别片段」 |

评价同时考虑在座比例、姿态异常频率与时长占比、超时离座频率，不采用可以互相抵消的总分。在座很久不能抵消长期低头，单次异常持续很久也不能因次数少获得高等级。

| 指标 | 统计口径 |
| --- | --- |
| 本次时长 | 自「首个实际写入的录像样本」起算至业务终点（endedOffset）；启动中不计入，准备定位计入并单独标注 |
| 在座 / 离座 / 回座 | 汇总本次全部可靠识别区间与时间点，准备和识别不确定单独展示 |
| 在座比例 | 参与评级的在座时长 ÷ 评级分母；建议休息不加入，具体集合待 D07 金样确认 |
| 姿态分项 | 低头 / 前倾、偏头、身体侧倾分别统计实际次数与持续时长 |
| 姿态异常频率 | 各项目按该项目在本次会话内的**有效在座检测时长**折算为每 30 分钟次数，再取最差分项判定；该项目有效在座检测时长不足 10 分钟时不做折算，改按门槛表第 1 行的绝对次数判档 |
| 姿态异常时长占比 | 各项目异常时长 ÷ 该项目有效检测的在座时长，再取最差分项判定 |
| 超时离座频率 | 超时离座次数按评级分母折算为每 30 分钟次数；集合待 D07 确认 |
| 数据说明 | 展示各项目实际检测时长，缺失项目显示未检测或暂无法判断 |

各姿态项目独立统计，避免新增侧倾检测后因为其偶尔不可见而丢弃已识别的低头事件。总姿态异常时长按各类区间并集合并，重叠不重复累加。每个项目的同一持续异常只计一次，重新校准或重复提醒不能制造重复次数。评价使用最差的已知分项，不把缺失项目当作优秀；部分项目缺失时明确等级仅反映已检测项目。

界面优先展示实际整数次数，折算指标放在详情。无有效时长的项目不执行除法、不参与该项档位比较。若整个区间只确认离座而没有在座，在座比例输出「不适用」，仍可依据超时离座频率与姿态分项评价；若所有行为指标均不可判断，则采用完成型评价。

| 等级 | 在座比例 | 各姿态异常频率 | 各姿态异常时长占比 | 超时离座频率 |
| --- | --- | --- | --- | --- |
| Great | ≥90% | ≤3 次 / 30 分钟 | ≤5% | 0 次 |
| Good | ≥2/3 | ≤6 次 / 30 分钟 | ≤15% | ≤1 次 / 30 分钟 |
| NotBad | 已有可判断的行为指标，未达到 Good | — | — | — |

先检查所有可判断指标是否达到 Great，再检查 Good，否则为 NotBad。Good 在座比例使用精确的 2/3。判定使用未四舍五入的值，配置调整应保持 Great 条件不宽于 Good；本次评价保存后，不因下一次调参改变。评级分母扣除合理离座与建议休息；展示离座和有效覆盖率另按其集合定义，不与评级分母混用，具体口径待 D07 确认。等级同时受有效覆盖率门槛封顶约束，覆盖率不足时不得因在座比例高而评为 Great。

各分项仅用自身有效在座时长计算频率和占比，不能用总会话时长稀释异常。首次合理离座、建议休息及关闭离座检测时的展示与评级分母存在独立集合定义；当前实现公式见[技术文档](../技术文档/主.md#评价计算)，产品金样待确认项见[设计约束与待确认事项](../评审与验收/设计约束与待确认事项.md)。在该项闭环前，不以代码输出反填验收预期。
