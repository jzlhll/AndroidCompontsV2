# 儿童监控交互设计 V1 本次结算

[返回主文档](主.md)

## 入口与展示条件

本次监控停止、保存结果明确后进入；也可从[视频播放](相册管理.md#视频播放)再次查看。超过 3 分钟生成评价，不超过 3 分钟展示本次小结。统计区间、配置处理和等级判定见[主文档](主.md#7-评价规则)。

## 页面与操作

正常结束后呈现游戏通关式结算页：顶部为轻量礼花，中间显示 Great、Good 或 NotBad，配合鼓励短句；下方展示本次监控时长、在座时长、低头 / 前倾次数、偏头次数、身体侧倾次数、离座次数及超时次数。礼花短暂播放，内容和按钮无需等待动画结束即可操作。

底部提供「完成」回首页；存在可播放录像时提供「查看录像」进入[视频播放](相册管理.md#视频播放)。视频播放页可再次查看本次结算。正常等级统一采用鼓励表达，不用责备、健康诊断或「不专心」等无法直接观察的结论。

## 保存失败处理

结果页顶部展示保存状态卡，说明录像已保存、保存失败或只能保留部分记录。监控已停止，保存操作不重启录像、不重新计算本次评价。首次展示保存失败时不自动播放礼花，优先呈现处理入口。

| 状态 | 操作与结果 |
| --- | --- |
| 仍有可恢复录像内容 | 提供「重试保存」「放弃本次」和「稍后处理」；空间不足时增加「去清理」 |
| 正在重试 | 状态改为「正在保存」，重试按钮显示加载，暂不可重复提交、放弃或清理；默认最多等待 30 秒，成功更新为已保存，失败恢复操作入口并说明原因 |
| 录像无法恢复 | 明确「录像无法恢复，已保留现有记录」，不显示无效的重试按钮；提供「保留记录」和「放弃本次」 |
| 完全没有可保留内容 | 显示「本次内容未能保存」，提供「返回首页」，不提供查看录像或重试 |

「去清理」进入[相册管理](相册管理.md)的管理模式，默认不选中任何记录；本次待恢复记录不参与清理选择。清理完成返回本页，刷新空间提示，由用户点击「重试保存」，不自动启动监控。

「稍后处理」返回首页，保留可恢复内容及本次记录，相册显示「待保存」标识，点击该项进入本结果页继续处理。「保留记录」或完成操作返回首页，相册以「录像不可用」标识保留可查看统计。待保存状态下允许下一次监控，但启动前仍检查空间；一次重试正在执行时暂不允许开始新监控，离开页面不启动重复保存。

点击「放弃本次」先确认「删除本次录像及关联监控记录？」；确认后清理本次内容并回首页，取消则留在结果页，已有历史记录不受影响。删除失败保留本页与失败说明，允许重试删除。放弃或清理记录后的返回遵循相册的删除例外，不再回到已删除内容。

## 结算反馈

正常结束后，超过 3 分钟显示本次评价与短暂礼花；完成型评价同样给予完成鼓励，不将数据缺失解释成孩子表现不好。

锁屏或其他中断后，超过 3 分钟仍提供截至中断的本次评价，附中断原因和保存结果。返回应用先在首页展示中断提示卡，用户点击「查看本次结果」进入本页；卡片位置和保存中状态见[主文档](主.md#系统中断)。进入后不自动播放通关礼花；系统问题不作为姿态扣分项。

等级只描述本次已观察到的姿态表现，不等同于健康、学习效果或专注程度。先肯定完成本次练习，再选择一个有记录支持的具体建议，不对未检测项目提出负面结论。

| 评价 | 鼓励文案 |
| --- | --- |
| Great | 「太棒啦，这次坐得很稳，继续保持！」 |
| Good | 「完成啦！下次继续保持好坐姿哦。」 |
| NotBad | 「完成一次练习啦，下次一起坐得更端正！」 |
| 完成型评价 | 「完成啦，坚持了 X 分钟！调整一下摄像头，下次就能看到更多表现啦。」 |

低头较多时建议抬头，偏头较多时建议摆正头部，身体侧倾较多时建议坐正，普通离座超时较多时建议及时返回。应用建议的正常休息不出现在负面反馈中。
