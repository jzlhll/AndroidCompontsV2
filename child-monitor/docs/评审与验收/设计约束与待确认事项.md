# 儿童监控设计约束与待确认事项

适用 V1 主体及 V1.1 扩展。当前主体功能已有代码入口，完整构建、正式采集链路与目标设备验收尚缺通过证据。本文只保留长期设计约束和未闭环事项，不维护已完成开发阶段。

## 固定设计约束

1. Android 单 Activity、Compose / Nav3；应用级 Runtime 拥有采集和保存任务，页面退出不撤销已接受操作。
2. 录像与检测并发，480p 范围、无音轨；能力不满足阻止开始，不能静默降级。首个实际编码样本定义计时起点。
3. 全画面自动校准，完整人脸与双肩稳定采样；未知不能补正常或离开，SceneChange 与 FaceIncomplete 不新增姿态评分分项。
4. 同一 sessionId 关联录像、事实、提醒与评价；日期固定、路径相对、恢复不造副本，事实提交后推进检查点和生成评价。
5. 录像期间允许轻量检测、提醒与偏好调整；目标参数下次生效，暗屏等待与影响采集或删除录像的操作须停录。动态切换不重载模型或重绑摄像头，历史事实保留原配置；Room 与 DataStore 分别校验版本，读取失败不能覆盖默认值。
6. 提醒入队不等于播放，合理离座与建议休息只豁免实际可靠片段；历史评价快照不重算。
7. 完整删除与仅删录像先持久化意图；清理保护待恢复记录，成功后移除失效导航。家长授权离开前台即撤销，敏感查询和命令均检查。

## 待确认与验收门槛

| 编号 | 当前实现与缺口 | 必须补齐的结果 | 影响场景 |
| --- | --- | --- | --- |
| D06 | 当前按 2 Mbps × 30 分钟 × 1.2 预留及滚动低水位，目标可至 480 分钟或不限；不能承诺整段目标空间已保障 | 确认采用滚动停止策略还是保障完整目标，明确不限时估算；统一产品标准并提供实际码率、可用容量和长时证据 | A04、I02、L01 |
| D07 | 展示 ordinaryAway；评级扣首次合理离座，在座仅取 valid_Away 交集；覆盖率保留可靠合理离座。这些集合不可混称普通离座 | 确认展示、比例、超时与覆盖分母，包含休息、Unknown、部分/全程关闭离座的精确金样，不能以代码输出反填预期 | F06、F07、M 组 |
| D08 | 未确认相机/Surface/编码器/模型释放时保持禁用；当前保护出口为结束进程后恢复，结果访问受路由守卫影响 | 确认并验证迟到释放自动恢复和已有结果访问例外，或明确产品仅支持重启恢复；未闭环前保留故障恢复阻塞 | A06、K06 |
| D09 | 尚无固定受验机型、人工标注样本、误报/漏报阈值、时间误差容限及资源预算 | 确定正常读写、人脸不完整、物体变化、离开/返回、遮挡/多人/移动设备样本；明确持续时长、内存/温度/耗电预算后执行量化验收 | C、L 组 |
