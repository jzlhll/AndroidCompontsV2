# AGit

基于单 `ComponentActivity`、Material 3 Compose、Navigation 3、Koin 和 StateFlow 的 GitHub 客户端。

功能范围、界面状态与异常策略见 [docs/README.md](docs/README.md)，Git 操作边界见 [docs/git-workflow.md](docs/git-workflow.md)，结构与兼容性见 [docs/architecture.md](docs/architecture.md)。

最低支持 Android 13（API 33），Android Studio 运行配置选择 `agit` 模块。首次使用添加 Token 分组，再选择完整 clone、depth 浅 clone 或无Git 源码下载；尚无提交作者时通过 `Next` 设置作者邮箱后一起保存，姓名选填。
