# 客户端传输实现

## 连接与发现

手机通过 BLE 广播和扫描发现主机的 HTTP 地址，点击后重新获取模式。客户端页面复用 Fragment 作用域的 Koin ViewModel。

Android 10/11 扫描申请精确位置权限，Android 12 及以上申请扫描与连接权限。主机 IP 或端口变化时替换广播；退出后的权限回调和旧广播回调不能恢复旧地址。

HTTP 请求使用独立客户端，不经过全量请求日志或响应预读取拦截器；文件下载与上传均流式处理，业务失败由页面状态展示。

三种模式共用 `ClientWsClient`：首次连接及重连通过 HTTP 获取模式和 WebSocket 端口，初始化回包后才允许新操作；端口查询和 WebSocket 初始化分别限时 5 秒，超时进入重试。心跳间隔 12 秒，不重复轮询 HTTP 模式；主机切换模式会关闭连接，客户端重连时重新校验。失败后按 1、2、4、8 秒重试。主机模式变化时停止新操作并提示返回。主动退出不再重连，旧连接回调不能修改当前连接。

## 手机发送文件

- 解析 URI 的真实名称和大小；大小未知时复制到独立临时缓存，空文件明确提示。
- URI 去重，列表使用独立标识；逐文件显示准备、上传、合并校验、成功、失败和取消。
- 分片从 1 编号，按偏移精确读取，流式计算 MD5。合并成功响应返回后才记为完成。
- 单文件失败后继续其余文件；手动重试跳过成功项。取消准备或上传时中断请求并有界清理分片；合并中取消等待当前结果，再停止后续文件。
- 列表显示文件类型图标、上传平均速度；底部显示文件数量、总大小和完成数量。
- 断连后停止启动后续文件，重连不自动续发；确认模式变化时停止旧模式上传。

## 手机接收文件

- 首页提供全部本地下载记录入口，不依赖重新发现主机；离线可打开、导出、分享、删除文件或移除记录。重试需要重新进入对应主机的接收页面。
- 对方文件与本地下载记录独立展示。下载按主机 IP、HTTP 端口及每次尝试标识隔离。
- 前台服务持有下载请求，取消直接调用网络请求的取消方法，清理结束后允许重试；迟到回调不能覆盖新尝试。
- 独立临时文件完成长度校验后发布，下载与服务端合并共用加锁的命名与落盘入口，同名文件自动加序号。
- 支持打开、导出、分享、确认删除本地文件以及仅移除记录；完成和删除后刷新本地文件仓库。
- 下载列表显示文件类型图标、下载平均速度；远端列表显示文件数量和总大小，本地记录显示数量、总大小及已完成数量。存在大小未知的文件时不把部分大小当成总大小。
- 下载记录保存在应用私有目录；重启后未完成项标记为中断，完成项核对文件是否存在。移除记录保留文件，删除文件保留失效记录。

## 页面生命周期与聊天

传输活动期间暂停三分钟空闲提示；空闲时可继续或返回。离开发送页先确认停止，合并期间等待结果；离开接收页提示下载继续。Compose 按生命周期收集状态。

主机按正在处理的上传、合并和下载响应统计活动传输，期间暂停五分钟空闲退出。下载流关闭或上传处理结束后释放计数，全部结束后重新计算空闲时间，因此客户端退出接收页不会让仍在进行的下载因心跳停止而被误中断。

聊天使用服务端分配的身份和颜色，发送未能入队时保留输入；重连历史按发送者、时间和内容去重。当前协议没有送达确认，发送成功仅代表进入 WebSocket 发送队列。

主机聊天历史的初始化、追加和备份在同一临界区串行处理，UI 与 WebSocket 线程同时发送时不会相互覆盖。

## 协议与边界

HTTP 路径、WebSocket 消息名称及原请求字段保持兼容。合并成功响应新增 `data.fileName`，旧服务端未返回时客户端使用原名称；同名保护需要新版服务端。服务端按来源地址隔离分片，合并校验前不会删除已有文件。

本地接收文件的下载标识包含名称与内容摘要，同内容不同名称的文件不会合并。升级后需刷新远端文件列表，既有本地记录仍可使用。

文件仓库构造不执行磁盘扫描。刷新在后台串行执行，按路径、大小、修改时间复用本进程内的 MD5 缓存；上传落盘后直接登记文件与已校验摘要，不依赖页面监听。发送列表每次加载都会刷新文件元数据。

传输准备、合并及下载共用进程独立的临时目录；进程重新启动清理遗留临时文件，正常结束立即清理本次文件，不恢复未完成传输。

下载记录可跨重启保留；待发送列表及发送结果只保留在当前页面会话。断点续传不支持，其他可选扩展见 `plan-future.md`。

设备场景尚待按 `plan-checklist.md` 联调确认。
