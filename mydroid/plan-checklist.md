# 场景检查清单

准备两台处于同一 Wi-Fi 或热点网络的手机，分别作为主机和客户端；另准备浏览器访问主机地址。

- [ ] 连接：主机开启一种模式，客户端扫描并进入，检查双方连接状态。
- [ ] 发送：选择一个文件和一组文件发送，检查名称、大小、进度、平均速度、完成数量及主机收到的文件。
- [ ] 取消与重试：发送大文件时取消，再次发送；中途断网后恢复网络并重试。
- [ ] 文件边界：选择空文件、同名文件和重复文件，检查提示与列表状态；主机上同内容不同名称的文件应分别列出、分别下载。
- [ ] 下载：刷新对方列表，下载多个文件，尝试取消、重试和同名下载。
- [ ] 文件使用：下载完成后打开、保存、分享；主机移除文件后检查本地记录，再尝试删除本地文件。
- [ ] 聊天：双方发送中文、长文本并复制消息；断开重连，检查身份和历史是否重复。
- [ ] 模式与退出：主机切换模式或退出，检查客户端提示；持续传输超过三分钟，检查是否被空闲提示打断。
- [ ] 重新启动：下载完成后重启客户端，在不联网、不扫描主机时从首页查看并操作下载记录；有未完成任务时重启，检查中断状态和遗留临时文件清理。
- [ ] 并发隔离：两台客户端同时上传同名同内容文件，取消其中一台不影响另一台；下载取消后立即重试不被旧任务回调覆盖。
- [ ] 记录操作：移除记录保留文件，删除文件保留失效记录；外部删除后重新进入页面可识别失效。
- [ ] HTML 兼容：浏览器分别完成一次发送、下载和文本收发。
- [ ] 超时重连：模式接口正常但端口接口超过 5 秒无响应，确认退出连接中状态、有限重试并允许手动重连。
- [ ] 大文件与错误：大文件上传下载不全量读入内存；合并 MD5 校验失败显示明确原因，丢失合并响应才显示结果不确定。
- [ ] 长下载：客户端下载后退出接收页，主机保持前台且没有其他客户端心跳，持续传输超过五分钟不中断；完成或取消全部传输后恢复空闲退出。
- [ ] 发现兼容：Android 10/11 授予精确位置权限后能扫描；主机地址或端口变化后广播新地址，广播启动中退出页面不会留下旧广播。
- [ ] 文件仓库：已有大量大文件时首次进入列表保持界面可操作；重复刷新不重算未变化文件的 MD5；未打开接收文件列表时上传成功，随后进入发送列表能看到新文件。
- [ ] 聊天并发：主机与客户端同时发送多条不同消息，重连和重新进入聊天室后核对历史没有缺失。
