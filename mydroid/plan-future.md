# 后续可选功能

以下功能暂不实施，后续按实际需求单独规划。

| 功能 | 后续实现方向 |
|---|---|
| 断点续传 | 服务端提供已收分片查询或下载范围支持，客户端校验文件一致性后继续传输。 |
| 进程被杀后自动续传 | 在任务持久化基础上，补齐调度、文件访问权限、主机重连与恢复策略。 |
| 远端缩略图 | 服务端提供图片缩略图和视频封面接口，客户端按需加载并缓存。 |
| 多客户端群聊转发 | 明确房间与消息标识，由服务端转发消息，处理发送者排除、确认和去重。 |
| 文件批量操作 | 按需增加多选下载、批量保存和批量清理。 |
| 文件筛选与排序 | 按文件类型、名称、大小或时间筛选排序，方便浏览较多文件。 |
