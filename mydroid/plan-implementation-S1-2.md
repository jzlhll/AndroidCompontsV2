# 文件发送与会话约定

## 上传协议

文件与分片均串行发送，协议编号从 1 开始、读取偏移从 0 开始，保留浏览器的分片大小算法。每次尝试先清理相同来源、文件名和 MD5 的残留分片。读取不足或无法到达偏移时报错，不能上传截断内容。

准备、上传及取消清理期间锁定待发送列表。空文件不发请求，大小未知时先复制缓存确定。每项有独立标识，同名文件互不影响；成功项不重复发送，失败项允许手动重试。

上传达到 100% 仍处于合并校验状态。合并请求最多等待 120 秒；服务端明确返回失败时展示对应原因，仅在结果无法确认时提示先检查主机文件，不自动重发。取消准备或上传时中断任务；已经开始合并则等待当前结果再停止后续文件。失败和取消后的分片清理在不可取消区域最多等待 5 秒，清理失败明确提示。

服务端合并到临时文件，校验 MD5 后在临界区选择唯一名称并发布。原文件不覆盖，所有退出路径清理本次临时文件和已取出的分片。浏览器接口字段不变，成功响应增加实际保存的文件名。

## 连接状态

`ClientWsClient` 每页面一个实例。连接和每次重连先读取 `/get-mode` 与 `/read-websocket-ip-port`；模式使用枚举名称判断，不将本地化的初始化描述作为枚举。

收到有效初始化身份后才标记已连接。端口查询与 WebSocket 连接登记各最多等待 5 秒；查询超时按连接失败处理，应用心跳间隔 12 秒；未新增协议中不存在的 pong 要求。被动断开最多重试四次，间隔 1、2、4、8 秒，登记成功后重置次数。模式变化停止重连，手动重试不能越过模式限制。

状态和回调在主线程处理，递增连接标识隔离旧回调。主动关闭先标记关闭，再释放请求、定时任务和 socket。模式检查失败进入重连，模式变化禁止新任务。

## 传输与退出

独立 WebSocket 断开不直接否定正在进行的 HTTP 结果。上传结束当前文件后停止后续文件；下载仍由前台服务按 HTTP 结果完成。重连不自动重发文件。

用户触摸及聊天消息刷新空闲时间，传输期间暂停计时。空闲提示可继续或返回；用户离开发送页时等待取消清理或正在进行的合并结束。接收页退出不会取消下载。

## 验收

双机传输、网络异常、主机模式变化、页面重建和浏览器兼容性按 `plan-checklist.md` 核对；代码实现不代表设备场景已经通过。
